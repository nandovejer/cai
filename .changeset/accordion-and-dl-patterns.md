**New (`@cai-ds/core`)**

- `.cai-accordion` (`components/accordion.css`): joins a stack of native `<details>` into one block. With the same `name` on each, only one is open at a time (Chrome and Edge 120, Safari 17.2, Firefox 130; older browsers open them independently). A page for it in the docs.
- `elements/text.css`: pairs in a `dl` may be grouped in a `<div>`, with the same space between groups. The docs show three patterns on the Text blocks page: metadata, key and value pairs, glossary.
