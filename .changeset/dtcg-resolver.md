The three color modes as the DTCG specification puts them: a resolver file.

**New (`@cai-ds/tokens`)**

- `@cai-ds/tokens/dtcg/resolver` → `dist/cai-tokens.resolver.json`, a Resolver Module 2025.10 document. Its base set is `cai-tokens.dtcg.json`; the modifier `mode` has the contexts `light`, `dark` and `high-contrast`, each with the whole semantic group for that mode (aliases to primitives kept), and `light` is the default. Generated by `pnpm tokens:build` from the same sources as the CSS.
- `cai-tokens.dtcg.json` is unchanged. The Format Module has no modes, so its `$extensions.mode` stays as the convention Tokens Studio and Terrazzo read.

**Checked:** both files validate against the official 2025.10 JSON Schemas (kept in `tests/fixtures/dtcg/`, no network), and a test checks that each context gives every semantic token the value the token file has for that mode. No tool has loaded the resolver file yet; the Tokens in Figma page says so.

`ajv` is a dev dependency, for that test only: no runtime dependency changes.
