New package: `@luz-ds/check`, a command line (`npx @luz-ds/check`, the bin is `luz-check`) that reads the HTML and CSS of a project that uses LUZ and says what is wrong with them, offline. It is a tool for the person who writes the page and for the AI agent that writes it for them: it has no CSS, no layer and no dependency, imports only `node:fs`, `node:path` and `node:url`, and opens no connection. This version has the options `--help` and `--version`, the exit codes 0, 1 and 2, and the rules of names: it blocks a `luz-*` class, a `<luz-*>` tag or an attribute of one that no manifest has, says the closest name, and warns about a `data-luz-*` attribute LUZ does not read and about a stylesheet that defines a class with LUZ's prefix. It reads the manifests of the packages in your `node_modules` and, for a project that uses a CDN, a snapshot of this release that it carries as data; the report says which each package came from. The rules of load order, misuse and theme colours follow. It needs Node 20 or later and has its own version, apart from tokens, core and site.
