The docs, the home page (English, Spanish and Arabic) and the READMEs now say the same about three things. Fonts: ET Book is the face of running text and headings; controls, labels, tables and navigation use the system sans, and code the system mono. Looks: CAI ships one look, Vejer, which is the default value of the semantic tokens in the three color modes, and no theme file; `cai.themes` is the empty layer for a look of your own, and overriding tokens is what making a theme is. Install: the home page heading is "Start with one link tag per layer" (it said "one link tag" over a snippet with two), and the docs hub no longer counts CDN tags. The `fonts.css` comment, the tokens README and the platform README (the image placeholder is in the colours of the default look, not of "the vejer theme") are corrected too. No code changes.
