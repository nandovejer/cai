## W-01 (Fonts) Architectural Impact

**Critical: External Runtime Dependency Removal**

The removal of Google Fonts from theme files is aligned with vanilla-first principles:

- ❌ **Before:** `@import url('https://fonts.googleapis.com/...')` — runtime network request
- ✅ **After:** Local `@font-face` definitions (network-independent)

**Documentation provided:**

- `DIST-RULES.md` now includes "Custom Fonts in Theme Files" section
- Fonts can be downloaded and integrated by maintainers
- Theme files have commented-out `src:` properties ready for local files

**This is a breaking change in terms of distribution:** ⚠️

- Themes currently have no font `src:` (fonts not yet bundled)
- Migration path is clear and documented
- No runtime errors; falls back to system fonts until migration completes

**Compliance:** ✅ Removes external dependency, aligns with architecture

## W-03 (predev Hook) Compliance

The `predev` hook ensures that `pnpm dev` always regenerates `dist/` before starting the dev server:

- ✅ Removes the **undocumented prerequisite** (run `pnpm build` first)
- ✅ Improves DX without adding runtime dependencies
- ✅ Maintains vanilla-first promise (no change to output)

**Potential concern:** Build on every `pnpm dev` startup adds ~500ms latency.  
**Mitigation:** Documented in README; developers can run specific build commands (`pnpm core:build`) if making targeted changes.
