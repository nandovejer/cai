Code Design

Code

How it works

A block with an icon, a title and a body. The type is written in the title, not only in the colour.

Keyboard and ARIA

Not interactive. If it appears after an action, put it in a live region (role="status" or role="alert") so it is announced.

Writing the content is in the Design tab.

Design

When to use

To tell the reader about a state that matters on the page: information, success, warning, error.

When not to use

For a message that must interrupt: use a dialog. Do not stack more than one or two alerts.

Writing the content

Say what happened and what to do next. "The build failed. Check the log and run it again."

Keyboard and ARIA are in the Code tab.
