Known issues

None known.

When to use

To show where the page sits in a hierarchy of three or more levels.

When not to use

On a flat site, or as the only way to navigate.

How it works

A nav landmark with links and separators. The last item is the current page with aria-current="page".

Content guidance

Use the page titles. Do not repeat the current page as a link.

Keyboard and ARIA

Each ancestor is a normal link in the tab order.
