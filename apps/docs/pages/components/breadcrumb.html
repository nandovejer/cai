Copy the markup

HTML 
<nav aria-label="Breadcrumb">
  <div class="cai-breadcrumb">
    <a class="cai-breadcrumb__item" href="/">Home</a>
    <span class="cai-breadcrumb__sep" aria-hidden="true">/</span>
    <a class="cai-breadcrumb__item" href="/settings/">Settings</a>
    <span class="cai-breadcrumb__sep" aria-hidden="true">/</span>
    <span class="cai-breadcrumb__item" aria-current="page">Billing</span>
  </div>
</nav>

Variants and options

There are no modifiers. The separator is your character: "/" and "›" are common.

Class or attributeWhat it does

.cai-breadcrumb__item

aria-current="page"
Marks the current page: primary text colour and medium weight
.cai-breadcrumb__sep
The separator, in the muted text colour

How it works

A <nav> landmark around a wrapping row of links, styled by components/breadcrumb.css. No JavaScript.

  • The current page is a <span>, not a link to itself.
  • The separators are hidden from assistive technology.

Without JavaScript

Nothing changes: the breadcrumb is links and CSS.

Keyboard and ARIA

Tab reaches each parent link in order; Enter follows it. The current page is not in the tab order.

  • Name the <nav> "Breadcrumb" with aria-label, so it differs from the main navigation.
  • aria-current="page" tells screen readers which item is the current page.

Writing the content is in the Design tab.

Design

When to use

Use a breadcrumb when pages sit three or more levels deep, so the reader sees where they are and can go up a level.

When not to use

Do not use a breadcrumb on a flat site, or as the only navigation.

  • For the main sections of a site, use a sidebar or a header navigation.
  • For steps in a process, show the step number in the page heading instead.

Writing the content

Use the title of each page, shortened if it is long.

  • Start at the home or the top of the section.
  • End with the current page, as text, not as a link.
