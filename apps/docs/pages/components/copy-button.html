The button copies the text in its data-copy attribute.

Known issues

Needs a secure context (https or localhost) for the Clipboard API; the failure is announced and the text can still be selected.

Code Design

Code

How it works

A button with data-copy. It needs JavaScript and the Clipboard API, so it is hidden until the script runs; the text it copies is always on the page, selectable.

Keyboard and ARIA

Tab, then Enter or Space. A polite status message announces "Copied to clipboard" or the failure.

Writing the content is in the Design tab.

Design

When to use

To copy a short string the reader will paste elsewhere, such as a command or a token name.

When not to use

For long text, or where selecting the text is enough. Never as the only way to get the content.

Writing the content

Name what is copied in the accessible name: "Copy the install command". The visible label is "Copy"; the result is announced in a polite live region.

Keyboard and ARIA are in the Code tab.
