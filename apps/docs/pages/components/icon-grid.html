Variants and options

There are no modifiers. The grid fits as many columns of at least 100 px as the width allows.

ClassWhat it does
.cai-icon-grid
The list: a grid with no bullets
.cai-icon-item
One bordered cell: icon, name, copy button
.cai-icon-display
A 48 × 48 px box that centres the icon, in the secondary text colour
.cai-icon-name
The name under the icon

How it works

A <ul> of icons, styled by components/icon-grid.css. The copy buttons are copy buttons, wired by clipboard.js.

  • Each button carries the icon's SVG, escaped, in data-copy.
  • CAI ships the grid, not an icon set: the four icons above belong to this page.

Without JavaScript

The copy buttons are hidden. The grid still shows every icon and its name.

Keyboard and ARIA

Tab reaches each copy button; Enter or Space copies the SVG.

  • Each button is named by its own text and the icon's name, with aria-labelledby: "Copy SVG Plus".
  • The icons are aria-hidden="true": the name is the text under them.
  • The result of each copy is announced in a polite live region.

Writing the content is in the Design tab.

Design

When to use

Use an icon grid to let readers browse a set of icons and copy the one they need.

When not to use

Do not use it to lay out icons that do something: it is a catalogue, not a toolbar.

  • For a row of actions, use buttons with text in an action group.
  • Never use an icon as the only label of an action.

Writing the content

Name each icon by what it shows, in one word if you can: "Plus", "Check", "Arrow".

  • Keep names unique in one grid.
  • Draw every icon on the same grid and stroke, with currentColor, so it follows the text colour in every mode.
