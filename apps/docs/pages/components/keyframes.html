Use a keyframe

Name the keyframe in your own animation, and take its duration from a motion token.

CSS 
.panel[open] {
  animation: cai-slide-up var(--cai-duration-base) var(--cai-easing-enter);
}
  • Under reduced motion every --cai-duration-* token is 0s, so the animation does not run and the element shows in its final state.
  • A hard-coded duration ignores reduced motion: never write one.
  • Do not loop an animation for ever: stop it when the task ends.
