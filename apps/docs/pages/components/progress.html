Known issues

None known.

When to use

To show how far a task that takes time has got.

When not to use

For a score or a measure within a known range: use a meter. Do not use it as a decorative bar.

How it works

The native progress element. The browser exposes the role and the value. No value attribute means indeterminate.

Content guidance

Name it with the figure: "Upload, 25%". Say what is happening, not just the number.

Keyboard and ARIA

Not interactive. Announce completion in a polite live region.
