.cai-nav-toggle

On small screens the sidebar becomes a drawer. This page's navigation uses it live.

Known issues

Without the popover API the navigation stays visible above the content.

When to use

For the main navigation of a documentation or app shell with many sections.

When not to use

For a short list of pages: a header navigation is simpler.

How it works

A nav landmark. On small screens it is a native popover drawer opened by a button with popovertarget, .cai-nav-toggle. Put that button first in your header row, so the focus order follows the screen; .cai-nav-toggle--fixed pins it to the top start corner instead, for a page with no header.

Content guidance

Section labels are nouns.

Keyboard and ARIA

Escape and a click outside close the drawer; focus returns to the button.
