.cai-nav-toggle

On small screens the sidebar becomes a drawer. This page's navigation uses it live.

Known issues

In a browser without the popover API the navigation does not become a drawer: it stays visible above the content on small screens.

<header>
  <button class="cai-nav-toggle" type="button" popovertarget="site-nav" aria-label="Menu">
    <span class="cai-nav-toggle__bar"></span>
    <span class="cai-nav-toggle__bar"></span>
    <span class="cai-nav-toggle__bar"></span>
  </button>

<nav class="cai-sidebar" id="site-nav" popover aria-label="Main">

    <div class="cai-sidebar__section-label">Account</div>

  </div>

How it works

A <nav> landmark, styled by components/sidebar.css. On small screens it is a native popover drawer.

  • The menu button opens it with popovertarget, with no script. The browser gives Escape, a click outside to close, the top layer and the expanded state.
  • initSidebar() from sidebar.js is optional: it marks the link of the section in view on a long page (aria-current="true") and closes the drawer when a link is followed. cai.js runs it.

Without JavaScript

The sidebar and the drawer work. The current link is the one your markup marks; it does not follow the scroll.

Keyboard and ARIA

Tab moves through the links in order. On small screens, the menu button opens the drawer; Escape or a click outside closes it, and focus goes back to the button.

  • Name the <nav> with aria-label when the page has more than one.
  • Mark the current page with aria-current="page" as well as .is-active: the class is only the look.
  • The menu button keeps the name "Menu" whether the drawer is open or closed; the popover exposes the state.

Contrast and focus are in the Design tab.

Design

When to use

Use a sidebar for the main navigation of an app or a documentation site with many sections.

When not to use

Do not use a sidebar for a site with a few pages: a header navigation is simpler.

  • For the trail to the current page, use a breadcrumb.
  • For panels of one page, use tabs.

Do and don't

Writing the content

Name each link after the page it opens, in a word or two.

  • Section labels are nouns: "Account", "Billing".
  • Order the links by how often people need them.

Measured from the token values of each mode, rounded down. Needs is the WCAG 2.2 AA minimum: 4.5:1 for text, 3:1 for focus rings, borders and icons.

  • Target: the menu button is 44 px square.
