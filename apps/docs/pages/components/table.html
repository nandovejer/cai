How it works

A native table with caption, thead and th scope. In a wrapper that scrolls and can take focus. Below 480px of container width each row becomes a card, using data-label.

Keyboard and ARIA

The scroll region is focusable so keyboard users can scroll it with the arrow keys. Sticky first column keeps the row name in view.

Writing the content is in the Design tab.

Design

When to use

To compare records across several attributes.

When not to use

For layout. For a short list of one attribute, use a list.

Writing the content

Column headings are short nouns. The caption names the table. Put units in the heading, not in every cell.

Keyboard and ARIA are in the Code tab.
