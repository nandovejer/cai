Known issues

None known.

When to use

To label an item with a short status or category, or to show a count.

When not to use

Not for actions: a tag is not clickable. Not for long text.

How it works

Inline spans with a colour modifier. Colour carries no meaning on its own: the text says it, and the dot variant adds a shape.

Content guidance

One or two words, sentence case. "Running", "Degraded", never only a colour name.

Keyboard and ARIA

Not interactive, so not focusable. A count badge needs context in the text next to it for screen readers.
