Human-first, AI-ready

LUZ is made for the person who uses the page. It starts from native HTML, works with a keyboard and with JavaScript off, and aims for WCAG 2.2 level AA in three color modes.

Plain HTML and CSS with a closed list of class names is also easy for an AI agent to get right. The site publishes the list of names, and a command checks what the agent wrote. Working with AI has the files and the prompt.

Tests first

Every change starts with a failing test. The first commit is a test: commit that fails without the change, and the change that follows makes it pass. A bug fix starts with the test that reproduces it.

One command, pnpm check:all, runs every check. The rules those checks enforce are in PRINCIPLES.md, and TESTING.md says how to write the test.

Zero dependencies

The packages have no runtime dependency. They ship plain CSS and small ES modules that need no build step, and they use the browser's own elements and APIs before any script.

Size budgets are a red line: a check fails when a file grows past its ceiling, and nobody raises a ceiling to make it pass. Everything LUZ ships is under the MIT licence, and only the MIT licence. Get started shows how to load it.
