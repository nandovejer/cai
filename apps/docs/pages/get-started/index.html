Pick a level, then copy one install command or the CDN tags. Each level needs the ones below it and nothing above.

!
Beta
Names, classes and behaviour can still change before the stable release. Pin an exact version, and read the changelog before you upgrade.

Which level do I need?

  • Your own components, CAI's colours and spacing: level 1, tokens only.
  • Ready-made buttons, forms, tables and dialogs: level 2, tokens and core.
  • Whole pages: shell, page header, footer, search: level 3, all three packages.
  • A landing page, with a feature grid and its blocks: level 3 and a package for that kind of site.

Level 1: tokens only

CSS custom properties: the colour, space and type scales, and the colours of light, dark and high contrast. No other CAI package is needed.

$ pnpm add @cai-ds/tokens
HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">

With a bundler such as Vite, import the files instead of adding tags. A href cannot name a package: these paths are for import only.

Bundler 
import "@cai-ds/tokens/css";
  • Running text and headings use ET Book, an MIT-licensed font that ships with the tokens. Controls, labels and tables use the system sans, and code the system mono.
  • Bringing your own fonts? Load dist/tokens.min.css instead: the same tokens without any @font-face.
  • Check your own colours against the WCAG ratios with npx @cai-ds/tokens check-contrast, or in the browser.

Level 2: tokens and core

The 25 components, the styles of bare HTML elements, and optional JavaScript. Load tokens first.

$ pnpm add @cai-ds/tokens @cai-ds/core
HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css">

<!-- Optional: copy buttons, tabs, players, the color mode -->
<script type="module" src="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.js"></script>
Bundler 
import "@cai-ds/tokens/css";
import "@cai-ds/core/css";

// Optional: copy buttons, tabs, players, the color mode
import "@cai-ds/core";
  • Every page works without the script. See what each JavaScript module adds.
  • Need a single component? Load dist/base.min.css plus the file you want, for example dist/components/button.min.css.
  • Markup you cannot add classes to, such as Markdown or a CMS? Load classless.css and mark the zone with data-cai-classless.

Level 3: tokens, core and site

Page patterns: the page shell, page header, sections, footer, image frame and site search. Site needs core and tokens.

$ pnpm add @cai-ds/tokens @cai-ds/core @cai-ds/site
HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/site@3.0.0/dist/site.min.css">

<!-- Optional: core behaviours, and the site search -->
<script type="module" src="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.js"></script>
<script type="module" src="https://cdn.jsdelivr.net/npm/@cai-ds/site@3.0.0/dist/site.min.js"></script>
Bundler 
import "@cai-ds/tokens/css";
import "@cai-ds/core/css";
import "@cai-ds/site/css";

// Optional: core behaviours, and the site search
import "@cai-ds/core";
import "@cai-ds/site";

Packages for one kind of site

On top of level 3, a package can add what one kind of site needs. Landing is the first: the feature grid, and blocks to copy for a landing page. It needs the three packages of level 3, loaded first.

$ pnpm add @cai-ds/tokens @cai-ds/core @cai-ds/site @cai-ds/landing
HTML 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/site@3.0.0/dist/site.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/landing@0.1.0/dist/landing.min.css">
  • Landing has its own version, 0.1.0 now, and needs version 3 of the other three. Pin both numbers.
  • With a bundler, add import "@cai-ds/landing/css"; after the imports of level 3.
  • It has no script: add the ones of level 3 if you want them.

Before you ship

  • npm and pnpm install the lower levels for you. Yarn only warns, so list every package, as above.
  • On a CDN, pin an exact version and add an integrity hash with crossorigin="anonymous". Compute the hash from the file you load, as below.
  • The core and site scripts warn in the console when the level below is missing.
  • Set lang on <html>: core's scripts write their text in that language (English and Spanish ship).
Shell 
curl -s https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css | openssl dgst -sha384 -binary | openssl base64 -A

Write the result as integrity="sha384-…" on the tag that loads that file, and repeat it for each file.
