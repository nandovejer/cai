Every CAI page works without JavaScript. The scripts add behaviour on top: copying, highlighting, a cycling color mode button, scroll spy, players and tabs.

Load all of it, or one module

HTML 
<script type="module" src="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.js"></script>
JS 
import { initTabs } from "@cai-ds/core/tabs";
initTabs();
  • cai.js starts every module when the page loads.
  • Importing a single module does nothing until you call its init function.
  • The site search is in @cai-ds/platform: see Search.
