Package boundaries

Each package depends on the ones above it in this list, never on the ones below.

@cai-ds/tokens   -> primitive and semantic tokens (standalone)
      ↓ required by
@cai-ds/core     -> components, bare-element styles, optional JS
      ↓ required by
@cai-ds/platform -> page patterns and the site search
  • Platform can use core and tokens; core can use tokens; tokens uses nothing.
  • The packages say so as required peer dependencies, and the core and platform scripts warn in the console when a level is missing.

CSS layers

Core's CSS comes in six native cascade layers (@layer), in ITCSS order. A later layer wins over an earlier one, and any CSS of yours that is not in a layer wins over all of core, with no !important.

packages/core/src/
  settings/_settings.css      1. settings    motion, z-index, breakpoints
  generic/_reset.css          2. generic     the reset
  elements/*.css              3. elements    bare HTML elements, zero specificity
  objects/_objects.css        4. objects     layout: .o-*
  components/*.css            5. components  the components: .cai-*
  utilities/_utilities.css    6. utilities   single-purpose helpers: .u-*
  • The components layer holds 20 components.
  • dist/cai.css holds all six layers. For a page that needs a few components only, load dist/base.css (settings, reset and elements), then dist/components/<name>.css for each one.
  • Rules for bare elements are wrapped in :where(), so any class wins over them.

The script

One optional entry point, cai.js, starts every behaviour on the page: color mode, copy buttons, dialogs, highlighting, players, tabs and the sidebar.

<script type="module" src="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.js"></script>

To load less, import one module and call its init function. See JavaScript modules.

<!doctype html>
<html lang="en" data-theme="light">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Sign up – Acme</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css">
</head>
<body>
  <main class="o-container">
    <h1>Sign up</h1>
    <div class="cai-field">
      <label class="cai-field__label" for="email">Email</label>
      <input class="cai-input" id="email" type="email" autocomplete="email">
    </div>
    <button class="cai-btn cai-btn--primary" type="submit">Create account</button>
  </main>
</body>
</html>
