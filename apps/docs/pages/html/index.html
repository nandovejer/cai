How to read a card

  • Live example. The real element, styled by LUZ right now. Change the color mode in the page footer to check it in all three.
  • Markup. The exact code of the example. The copy button copies what you see.
  • LUZ note. Whether the element is styled with no class, through a component class, or left to the browser.

Rules that style bare elements have zero specificity: any .luz-* class, or a rule of your own, wins.

Deprecated elements, and what to use

The 23 elements below are left out of the reference on purpose: they are obsolete or removed, and LUZ styles none of them. Use the replacement.

ElementUse insteadWhySource
acronym
abbr
The same job with the name that stayed.
HTML Standard: acronym
big
CSS: font-size, or strong or em when it carries emphasis
Size is a presentation matter.
HTML Standard: big
center
CSS: text-align: center for text, margin-inline: auto for a block
Alignment is a presentation matter.
HTML Standard: center
content
slot, with Shadow DOM version 1
Part of the first Shadow DOM, which browsers removed.
MDN: content
dir
ul
A list of files is a list.
HTML Standard: dir
fencedframe
iframe
A Privacy Sandbox experiment that is deprecated.
MDN: fencedframe
font
CSS: font-family, font-size and color
Fonts and colors are presentation.
HTML Standard: font
frame
iframe and CSS, or server-side includes
Frames split a window into documents; a layout does it with CSS.
HTML Standard: frame
frameset
iframe and CSS, or server-side includes
As for frame.
HTML Standard: frameset
image
img
Never part of a standard: browsers only kept it for old pages.
MDN: image
marquee
CSS animation, with prefers-reduced-motion respected
Moving text that cannot be paused fails WCAG 2.2.2.
HTML Standard: marquee
menuitem
A script on the contextmenu event, or a popover with buttons
The context-menu markup was never implemented widely and was removed.
HTML Standard: menuitem
nobr
CSS: white-space: nowrap
Line breaking is a presentation matter.
HTML Standard: nobr
noembed
object instead of embed, with fallback content inside
embed has no fallback of its own.
HTML Standard: noembed
noframes
iframe and CSS, or server-side includes
As for frame.
HTML Standard: noframes
param
The data attribute of object, which sets the URL of the resource
Parameters of a plug-in that no browser runs.
HTML Standard: param
plaintext
The text/plain type of the response
It could not be closed: the rest of the page became text.
HTML Standard: plaintext
rb
The base text directly inside ruby
The ruby base needs no wrapper.
HTML Standard: rb
rtc
Nested ruby elements
As for rb.
HTML Standard: rtc
shadow
slot, with Shadow DOM version 1
Part of the first Shadow DOM, which browsers removed.
MDN: shadow
strike
del for an edit, s for text that no longer applies
The element says what the text means, not how it is drawn.
HTML Standard: strike
tt
code, kbd, samp or var by meaning, or CSS font-family: monospace
Fixed width is a presentation matter.
HTML Standard: tt
xmp
pre with code, with < and & escaped
It could not hold its own end tag.
HTML Standard: xmp
