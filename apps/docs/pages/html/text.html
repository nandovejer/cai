Hold the reading content of a page: paragraphs, lists, quotations and preformatted text.

<blockquote>

MDN reference for the blockquote element

A longer quotation, set apart as its own block. Put the source URL in the cite attribute, and say who said it outside the quote, for example in a figcaption.

The best interface is the one the browser already ships.

HTML 
<blockquote>
  <p>The best interface is the one the browser already ships.</p>
</blockquote>

Styled by elements/text.css, with no class.

<dd>

MDN reference for the dd element

The value or explanation that follows a dt in a description list. One term can have several.

Token
A named design decision, stored as a variable.
HTML 
<dl>
  <dt>Token</dt>
  <dd>A named design decision, stored as a variable.</dd>
</dl>

Styled by elements/text.css, with no class.

<div>

MDN reference for the div element

A plain box that adds no meaning. Use it only when no other element fits, and give it a class that says what it is for.

First block
Second block
HTML 
<div class="o-stack">
  <div>First block</div>
  <div>Second block</div>
</div>

CAI adds no style: the browser look is kept. CAI adds no style. The o-stack layout object spaces the children.

<dl>

MDN reference for the dl element

A list of names paired with values: a glossary, product specs, the details of a file. Each dt names something and the dd after it explains it.

Layer 1, standalone.
Core
Layer 2, requires tokens.
HTML 
<dl>
  <dt>Tokens</dt>
  <dd>Layer 1, standalone.</dd>
  <dt>Core</dt>
  <dd>Layer 2, requires tokens.</dd>
</dl>

Styled by elements/text.css, with no class.

<dt>

MDN reference for the dt element

The name half of a name and value pair in a description list, such as a word in a glossary. CAI sets it in a heavier weight.

Layer 3, app patterns.

<figcaption>

MDN reference for the figcaption element

The caption of a figure. Make it the first or the last child of the figure.

HTML 
<figure>
  <img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120">
  <figcaption>Two shapes, drawn in SVG.</figcaption>
</figure>

Styled by elements/text.css, with no class.

<figure>

MDN reference for the figure element

Wraps an image, a diagram, a code listing or a quote that the text refers to, with an optional caption. It could move elsewhere on the page without breaking the text.

HTML 
<figure>
  <img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120">
  <figcaption>Two shapes, drawn in SVG.</figcaption>
</figure>

Styled by elements/text.css, with no class. CAI makes a bare figure a padded surface. The .cai-figure component adds more.

<hr>

MDN reference for the hr element

Marks a change of topic or scene between paragraphs. Use it for that meaning, not as a decorative line: for a plain line, use a border.

Above the break.

Below the break.

HTML 
<p>Above the break.</p>
<hr>
<p>Below the break.</p>

Styled by elements/text.css, with no class.

<menu>

MDN reference for the menu element

A list of actions the user can take, such as the buttons of a toolbar. Browsers treat it like a ul; CAI lays it out as a row.

    •
    HTML 
    <menu>
  <li><button class="cai-btn cai-btn--outline cai-btn--sm" type="button">Cut</button></li>
  <li><button class="cai-btn cai-btn--outline cai-btn--sm" type="button">Copy</button></li>
  <li><button class="cai-btn cai-btn--outline cai-btn--sm" type="button">Paste</button></li>
</menu>

    Styled by elements/text.css, with no class.

    <ol>

    MDN reference for the ol element

    <p>

    MDN reference for the p element

    One paragraph of text. CAI asks the browser to avoid leaving a single word alone on the last line.

    CAI is a vanilla design system: tokens, components and app patterns in plain CSS and ES modules, with no framework and no build step.

    HTML 
    <p>CAI is a vanilla design system: tokens, components and app patterns in plain CSS and ES modules, with no framework and no build step.</p>

    Styled by elements/text.css, with no class.

    <pre>

    MDN reference for the pre element

    Text shown exactly as typed, with every space and line break, in a fixed-width font. For code, add the .cai-code-block class and a code element.

            $ pnpm add @cai-ds/core

    <pre>$ pnpm add @cai-ds/tokens
$ pnpm add @cai-ds/core</pre>

    Styled by elements/text.css, with no class.
