.cai-platform-actions
A wrapping row with 8 px between items; at 480 px and below each item takes the full width, one per line

How it works

A flex row from @cai-ds/platform. No JavaScript.

  • Put buttons and links styled as buttons inside it.
  • On a phone the actions stack, so each one stays an easy target.

Without JavaScript

Nothing changes: the group is CSS, and each control keeps its native behaviour.

Keyboard and ARIA

Tab moves through the actions in source order, which is also the order on screen.

  • Each control keeps its own keys: Enter for a link, Enter or Space for a button.
  • No role is needed. Add role="group" and a name only if the group needs a label of its own.

Writing the content is in the Design tab.

Design

When to use

Use an action group for two or three related actions, such as the buttons at the end of a form or in a hero.

When not to use

Do not use it for navigation or for long lists of links: use a <nav> with a list.

  • No more than three actions: with more, the reader cannot tell which one matters.

Writing the content

Put the main action first, as the only primary button.

  • Each label starts with a verb and makes sense on its own: "Save details", "Browse the components".
  • Use <a> to go somewhere and <button> to do something.
