When to use

To show one terminal command that readers copy, such as an install command.

When not to use

For several lines of code or output: use a code block. Not for commands the reader must edit before running without saying so.

How it works

A box with the command in <code> and a native copy button. The prompt sign is decorative and cannot be selected. Without JavaScript the copy button is hidden and the command can still be selected and copied.

Content guidance

Show the command exactly as it should run. Name the copy button by what it copies, for example "Copy install command".

Keyboard and ARIA

Tab reaches the copy button; Enter or Space copies. The result is announced in a polite live region.
