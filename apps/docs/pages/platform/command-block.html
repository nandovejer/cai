Variants and options

There are no modifiers.

How it works

A box from @cai-ds/platform with the command in a <code> and a core copy button.

  • The button copies its data-copy: the command without the prompt.
  • At 480 px and below the button takes the full width, under the command.

Without JavaScript

The copy button is hidden. The command stays on screen, and the reader selects and copies it; the prompt is not selected with it.

Keyboard and ARIA

Tab reaches the copy button; Enter or Space copies.

  • The prompt sign is aria-hidden="true", so screen readers read the command only.
  • The result is announced in a polite live region.
  • The focus ring on the button uses the primary text colour, for contrast on the strong surface.

Writing the content is in the Design tab.

Design

When to use

Use a command block for one terminal command the reader copies and runs, such as an install command.

When not to use

Do not use it for several lines of code or for output.

  • For code or output, use a code block.
  • For a command the reader must change before running it, say what to change, next to it.

Writing the content

Show the command exactly as it should run.

  • Name the copy button by what it copies: "Copy the install command".
