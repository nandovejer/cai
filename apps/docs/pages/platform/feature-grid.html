ClassEffect
.cai-platform-feature-grid
Two equal columns with 12 px between cells; one column at 768 px and below

How it works

CSS grid from @cai-ds/platform. No JavaScript.

  • Each cell is usually a card.

Without JavaScript

Nothing changes: the grid is CSS.

Keyboard and ARIA

The grid has no interaction of its own.

  • To link a card, put the link on its title text and keep the rest plain: one tab stop per card.
  • Give each card a heading, so screen reader users can move from card to card.

Contrast and focus are in the Design tab.

Design

When to use

Use a feature grid for a short set of features or options of equal weight, each in its own card.

When not to use

Do not use it for data that readers compare across rows: use a table.

  • For items with an order, use a numbered list.
  • For a single item, use a card on its own.

Do and don't

Writing the content

Keep the cards parallel: the same heading level and one or two sentences each.

  • An even number of items fills the two columns.

Contrast and focus

The grid adds no colour of its own: the cards in it keep the pairs on the card page.

  • Focus: the grid takes none; what is inside keeps its own ring.

Tokens it uses

The 1 tokens that the .cai-platform-feature-grid rules of platform's components/_components.css reads, by family. Each family links to its page, with the values in every mode. In Figma they are variables with the same names: see Tokens in Figma.
