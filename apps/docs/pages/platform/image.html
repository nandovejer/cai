Ratios: 16:9, --4x3, --3x2, --1x1, --21x9, --9x16.

Known issues

In forced-colors mode browsers drop the placeholder, and the frame shows a thin border instead. If an image fails to load, some browsers add a broken-image icon next to its alt text. The night version follows a dark mode set on a page or a section, but not a light section inside a dark one.

Copy the markup

<div class="cai-platform-image">
  <picture>
    <source type="image/avif" srcset="dunes-640.avif 640w, dunes-1280.avif 1280w" sizes="(min-width: 768px) 50vw, 100vw">
    <source type="image/webp" srcset="dunes-640.webp 640w, dunes-1280.webp 1280w" sizes="(min-width: 768px) 50vw, 100vw">
    <img src="dunes-1280.jpg" srcset="dunes-640.jpg 640w, dunes-1280.jpg 1280w" sizes="(min-width: 768px) 50vw, 100vw"
      width="1280" height="720" alt="Sand dunes under a low sun" loading="lazy" decoding="async">
  </picture>
</div>

To show the placeholder on purpose, point the <picture> at the files in dist/placeholders/. It is decorative, so its alt text is empty.

Replace placeholders/ with https://cdn.jsdelivr.net/npm/@cai-ds/platform@3.0.0/dist/placeholders/, or with the path where your bundler serves the package.

The placeholder files are named placeholder-<ratio>-<width>, with the ratio as 16x9, 4x3, 3x2, 1x1, 21x9 or 9x16.

  • Widths 640, 1280 and 1920 in AVIF and WebP, 640 and 1280 in JPEG. For 9x16: 360, 720 and 1080, and JPEG up to 720.
  • placeholder-night- for the night version.
  • placeholder.svg and placeholder-night.svg fit any size.

How it works

A <div> of fixed aspect ratio around a native <picture>, styled by @cai-ds/platform. No JavaScript.

  • The image fills the frame and is cropped to it.
  • A frame with no image shows an abstract placeholder as its background, in the colours of the vejer theme, in AVIF, WebP or JPEG through image-set().
  • In dark mode the placeholder is a night version; high contrast keeps the day version.
  • While an image loads, or if it fails, the frame shows a flat surface, and a failed image's alt text is drawn on it. Transparent PNG and SVG images sit on that surface too.

Without JavaScript

Nothing changes: the frame, the image and the placeholder are HTML and CSS. Without CSS the image shows at its own size.

Keyboard and ARIA

The frame has no interaction of its own.

  • Screen readers announce the <img> by its alt text and skip the placeholder: an empty frame announces nothing.
  • Do not add a role or an aria-label to the frame.
  • If the image is a link, the link takes its name from the alt text, which must then say where it goes.

Writing the content is in the Design tab.

Design

When to use

Use the image frame for a picture in a box of fixed shape, such as a card cover or an article header, when the picture may be missing.

  • Content from people or from a content system.
  • A page built before its images exist.

When not to use

Do not use it for an image that must keep its own shape, such as a chart or a screenshot: the frame crops it.

  • For a chart or a diagram with a caption, use a figure.
  • For icons and logos, use an <img> or an SVG at its own size.
  • Never let the placeholder stand in for an image that carries information: if it is missing, say so in text.

Writing the content

Give every real image an alt text that says what it shows, in one plain sentence.

  • Use alt="" when the image is decorative, or the text next to it already says the same.
  • Never describe the placeholder: it is a background and nothing reads it out.
  • The frame crops: keep text and essential detail away from the edges, and describe what stays visible.
  • Set width and height to the image's own size, so the page does not jump while it loads.
  • Add loading="lazy" only below the fold; an image visible when the page opens should load at once.
  • Do not put text in images.
