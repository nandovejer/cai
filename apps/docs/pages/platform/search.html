Example

A–Z index

The same search as the one in this site’s header. Without JavaScript the button is a link to the A–Z index.

Known issues

The search has not been tested with a screen reader yet. Ctrl+K opens this search instead of the browser’s own web search box: use the address bar to search the web. At 400 percent zoom the whole dialog scrolls, so the field can move out of view while you read the results.

Code

Copy the markup

The trigger, with the link it replaces, goes in the header. The dialog goes once per page, anywhere in <body>. Every text is yours: write it in the page’s language.

<a href="/a-z/" data-cai-search-fallback>A–Z index</a>
<button class="cai-platform-search-trigger" type="button" data-cai-search-open
        aria-haspopup="dialog" aria-keyshortcuts="Control+K Meta+K" hidden>
  <span class="cai-platform-search-trigger__label">Search docs…</span>
  <kbd class="cai-platform-search-trigger__key" aria-hidden="true">Ctrl K</kbd>
</button>

<dialog class="cai-modal cai-platform-search" aria-labelledby="search-title"
        data-cai-search data-cai-search-src="/search-index.json"
        data-cai-label-results="{n} results"
        data-cai-label-result="1 result"
        data-cai-label-capped="{shown} of {n} results. Type more to narrow them."
        data-cai-label-none="No results for “{query}”."
        data-cai-label-loading="Loading the search index…"
        data-cai-label-error="Search is not available right now.">
  <search class="cai-platform-search__body">
    <div class="cai-platform-search__head">
      <h2 class="cai-platform-search__title" id="search-title"><label for="search-q">Search the documentation</label></h2>
      <form method="dialog"><button class="cai-btn cai-btn--ghost cai-platform-search__close">Close search</button></form>
    </div>
    <input class="cai-input" id="search-q" type="text" maxlength="100" autocomplete="off"
           spellcheck="false" enterkeyhint="go" autofocus aria-describedby="search-hint">
    <p class="cai-field__helper" id="search-hint">Results update as you type. Use the arrow keys to move through them.</p>
    <p role="status"></p>
    <p data-cai-search-show="none" hidden>Check the spelling or try a shorter word.</p>

Variants and options

  • .cai-platform-search-trigger--compact: at 768 pixels and below, the trigger shows the magnifier only; its name stays the label text. Add an <svg class="cai-platform-search-trigger__icon"> for it.
  • More than one trigger: every [data-cai-search-open] opens the dialog (this site has one in the header and one on the documentation home).
  • An element with data-cai-search-show="idle" inside [data-cai-search-results] shows while the field is empty, for example a short list of popular pages; one with data-cai-search-show="none" shows when nothing matches.
  • Leave out a [data-cai-search-list] to leave out that group.
  • The texts the script writes are the data-cai-label-* attributes of the dialog: results, result, capped, none, loading and error, with {n}, {shown} and {query} in them. A missing label writes nothing.

How it works

Load platform.min.js, or import initSearch from @cai-ds/platform/search and call it. It shows the button, hides the link, and opens the native <dialog> with showModal(): the browser traps the focus, closes it with Escape and returns the focus. The first time it opens, it reads the index.

The index is a JSON file, version 1. Each list holds [text, url, meta, lang]; meta (shown muted after the text) and lang are optional, and URLs are relative to the file:

{
  "version": 1,
  "pages": [["Button", "components/button/", "Components"]],
  "sections": [["When to use, Button › Design", "components/button/#when"]],
  "elements": [["<table> element, Tables", "html/tables/#el-table"]]
}

A result matches when its text contains every word typed, without regard to case or accents; the ones that start with the words come first. Each group shows 8 results at most, and the status line says how many there are.

What the component accepts, so that an index built from a CMS cannot harm the page:

  • The JSON comes only from the page’s own origin, over http or https, and a redirect fails the request. Your Content-Security-Policy needs connect-src 'self'; to use an index from another site, host a copy on yours. The browser caches it like any file.
  • Links are only http: and https: URLs; any other item is left out. Text is written as text, never as HTML.
  • Limits: 1,000,000 characters of JSON, 10,000 results, 300 characters a text, 8 words a search, 100 characters in the field. Unknown fields are ignored. An index that is not version 1 shows the error text.

Without JavaScript

The button stays hidden and the link shows: write a page that lists every page by name, such as an A–Z index. The dialog is never opened.

Keyboard and ARIA

  • Ctrl + K or ⌘ + K opens the search from anywhere on the page, except while typing in a text area or an editable region, or while another dialog is open. Pressed again, it selects the text in the field.
  • Down arrow moves from the field to the first result; Down and Up move between results, across groups; Home and End go to the first and last. Up on the first result goes back to the field.
  • Enter in the field opens the first result; on a result it follows the link. Typing on a result goes back to the field.
  • Escape or Close search closes the dialog, whatever the field holds, and the focus returns to where it was. The field is type="text" for that reason: in a type="search" field, Chrome and Safari use the first Escape to clear the text. A result on the same page closes it and moves the focus to that section’s heading.
  • The heading names the dialog and labels the field. The count is announced once the reader stops typing (role="status"). Results are links in lists under headings, not a combobox.

Design

When to use

On a site of more than a few pages, where readers look for something by its name: a component, a setting, an article title.

When not to use

Instead of navigation: the menu and an index page stay, because search needs typing and a name the reader may not know. Not for searching inside long texts or across many sites: this matches titles and headings only.

Writing the content

  • The trigger says what is searched: “Search docs…”. Keep it short in every language (“Buscar…”) rather than cutting it off.
  • Give section results their page: “When to use, Button › Design”, so a result makes sense on its own.
  • Point the fallback link and the line under the results at the same index page.

Contrast and focus

The trigger’s text is full-contrast text, not placeholder grey, inside a field-like border. The focused result has the same focus ring as every link; in forced colors the dialog keeps a border.
