Example

This page has one: press Tab at the top of the page to see it.

Known issues

None known.

Copy the markup

<a class="cai-platform-skip-link" href="#main-content">Skip to main content</a>

When to use

On every page that has navigation or a header before the main content.

When not to use

As the only way to reach the content: the page still needs a logical heading order and landmarks.

How it works

A normal link to the id of <main>, first in <body>. It sits off screen and slides in when it receives focus. The browser does the jump; no JavaScript.

Content guidance

Say where it goes: "Skip to main content". Do not add other text.

Keyboard and ARIA

Tab once from the top of the page to reveal it; Enter follows it and moves focus to the main area. Under reduced motion it appears without sliding.
