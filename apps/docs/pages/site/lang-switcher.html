Language

The links go to this site’s home page in each language. The list opens under the header, at the end of the row, as it does on the home page; this documentation is in English only.

Known issues

The list opens at a fixed place under the header, not under its button: placing it next to the button needs CSS anchor positioning, which is not yet available in every browser. Below 360 px wide the button shows the globe only, to keep the header on one row; the language’s name is still its accessible name, so a sighted reader has to recognise the globe. It has not been tested with a screen reader yet.

Code Design

Code

Copy the markup

One link per language, to the same page in that language, in the header of every translated page. On each page mark its own language with aria-current="page" and write the label in the page’s language.

HTML 
<div class="cai-site-lang-switcher">
  <button class="cai-site-lang-switcher__button" type="button" popovertarget="lang-menu">
    <span class="u-sr-only">Language: </span><span class="cai-site-lang-switcher__name">English</span>
  </button>
  <nav class="cai-site-lang-switcher__menu" id="lang-menu" popover aria-labelledby="lang-title">
    <p class="cai-site-lang-switcher__title" id="lang-title">Language</p>
    <ul class="cai-site-lang-switcher__list">
      <li><a class="cai-site-lang-switcher__link" href="/" hreflang="en" lang="en" aria-current="page">English</a></li>
      <li><a class="cai-site-lang-switcher__link" href="/es/" hreflang="es" lang="es">Español</a></li>
      <li><a class="cai-site-lang-switcher__link" href="/ar/" hreflang="ar" lang="ar">العربية</a></li>
    </ul>
  </nav>
</div>

How it works

Changing language is going to another page, so the switcher is a list of links. The button opens it with the native popovertarget, and @cai-ds/site only styles it: there is no script.

  • Each language is named in that language, with lang so a screen reader pronounces it, and hreflang so the link says where it goes.
  • The list is a popover in the top layer, fixed under the header at the inline end; it mirrors in right-to-left text.
  • The page itself declares its language and direction: <html lang="ar" dir="rtl">. Add a <link rel="alternate" hreflang="…"> per language in the <head>, so search engines find the others.
  • Core switches Arabic text to the system sans and removes letter spacing from it: the serif has no Arabic letters, and spacing breaks the joins of the script.

Without JavaScript

Nothing changes: the button opens the list with the popover API, and the links are links. In a browser without the popover API the button is hidden and the links show in a row.

Keyboard and ARIA

Tab to the button and press Enter or Space to open the list; Tab moves through the languages and Enter follows one. Escape, or a click outside, closes the list.

  • The browser tells assistive technology whether the list is open, from popovertarget.
  • The button’s name is “Language: English”: what it is, then the visible text (WCAG 2.5.3). Below 360 px only the globe shows, and the name is the same.
  • The current language is a link with aria-current="page".

Design

When to use

Use it on a site whose pages exist in two languages or more, in the header of every translated page, at the same place on each.

When not to use

Do not add it to pages that exist in one language only, even if the rest of the site is translated.

  • Do not choose the language for the reader from the browser’s settings or their location: let them choose, and link each page to the others.
  • Do not use it to translate the page in place with a script: each language is a page of its own, with its own address.

It replaces nothing in CAI. It makes a <select> with a script that changes the address unnecessary.

Do and don't

Writing the content

Write each language’s name as its speakers write it: “English”, “Español”, “العربية”, never “EN” or a flag.

  • Write the label in the page’s language: “Language”, “Idioma”, “اللغة”.
  • List the languages in the same order on every page.
  • If some pages are not translated, link to the closest page that is, and say in its language that the rest is in another one.
