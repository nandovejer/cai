Example

Color mode (specimen)

The radio group the element wraps, disabled here because a working one would change the color mode of this whole page. Auto is the fourth radio, checked until the reader chooses. The switcher in this page's footer is core's, with three modes.

Known issues

Without the script for the head, a page that follows a dark system can flash the wrong mode before the element runs. The hours of by="clock" are fixed and read from the visitor's own clock: there is no sunrise or sunset for a place. The word Auto and the legend are yours to translate. A theme of your own listed in data-luz-themes is left to core. It has not been tested with a screen reader.

Code Design

Code

Copy the markup

Core's color mode switcher with a fourth radio, auto, checked, inside <luz-mode>. site.min.js loads the element's file, mode.min.js, when the browser is idle; a page without site.min.js loads that file on its own.

HTML 
<script type="module" src="https://cdn.jsdelivr.net/npm/@luz-ds/site@0.1.0/dist/site.min.js"></script>

<luz-mode remember by="clock">
  <fieldset class="luz-mode-switcher luz-mode-switcher--cycle">
    <legend class="luz-mode-switcher__label">Color mode</legend>
    <label class="luz-mode-btn"><input class="luz-mode-btn__input" type="radio" name="luz-theme" value="auto" checked>Auto</label>
    <label class="luz-mode-btn" data-theme="light"><input class="luz-mode-btn__input" type="radio" name="luz-theme" value="light">Light</label>
    <label class="luz-mode-btn" data-theme="dark"><input class="luz-mode-btn__input" type="radio" name="luz-theme" value="dark">Dark</label>
    <label class="luz-mode-btn" data-theme="high-contrast"><input class="luz-mode-btn__input" type="radio" name="luz-theme" value="high-contrast">High contrast</label>
  </fieldset>
</luz-mode>

Script for the head

This script avoids the flash of the wrong mode: it sets data-theme before the first paint, so a page that follows a dark system does not paint light first. It is recommended, not required, and is for by="system". It takes the mode stored under luz-theme, otherwise prefers-contrast, then prefers-color-scheme.

HTML 
<script>
  (function () {
    var m;
    try { m = localStorage.getItem("luz-theme"); } catch (e) {}
    if (["light", "dark", "high-contrast"].indexOf(m) < 0)
      m = matchMedia("(prefers-contrast: more)").matches ? "high-contrast"
        : matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light";
    document.documentElement.dataset.theme = m;
  })();
</script>

Variants and options

There are no variants. The attributes of <luz-mode>, and the value auto of the first radio:

Class or attributeEffect
remember
A boolean. Stores the choice under luz-theme, core's own key, and reads it on load. Auto removes the key. Without it nothing is read, and the key core writes is removed, so a reload starts in Auto
by
What Auto follows: system (the default) or clock
for
The id of the element that gets the attributes. <html> by default
light-attr
The name of the attribute that holds the phase of the day. data-light by default
data-light
Written on the target by by="clock": one of the six phases below

How it works

CSS from @luz-ds/site for the element's box and a file of its own, @luz-ds/site/mode (dist/mode.min.js), which defines <luz-mode>. site.min.js loads it when the browser is idle, and only on a page with a <luz-mode>. The radios are core's, and so are their labels: the element writes no text.

  • Auto by the system: prefers-contrast: more gives high-contrast; otherwise prefers-color-scheme: dark gives dark; otherwise light. It follows a change while the page is open, and writes no data-light.
  • Auto by the clock: prefers-contrast: more still wins. Otherwise the phase of the day, from the visitor's own clock, decides: dark in the dark phases, light in the others, and the phase is written as data-light. It checks again every minute and when the tab shows again.
  • A mode the reader chose: Light, Dark or High contrast sets data-theme to it. With by="clock" the light is pinned: Light is afternoon, Dark and High contrast are night.
  • Storage: only with remember, under core's luz-theme; a value that is not a mode is ignored. A theme of your own listed in data-luz-themes is left to core. Where storage is blocked, the choice holds for the page.
  • With luz.js: core's script wires the same radios and ignores Auto, and its cycle button steps through all four.

Two lights in one mode

With by="clock" the phase is data-light, and the rest is your CSS: set only the semantic tokens that differ, as a theme of your own does. Measure each pair with the contrast check, and use preview() to see each look.

CSS 
[data-theme="light"][data-light="morning"],
[data-theme="light"][data-light="afternoon"] {
  --luz-surface-page: #fdf3dc;
  --luz-surface-muted: #fdf3dc;
  --luz-surface: #fffaf0;
}

[data-theme="dark"][data-light="dusk"],
[data-theme="dark"][data-light="night"] {
  --luz-surface-page: #0f1520;
  --luz-surface-muted: #0f1520;
  --luz-surface: #172030;
}

Without JavaScript

The four radios show, even in the cycle variant, and core's tokens change the mode from the checked one. Auto is light, because no rule matches it. The system and the clock are not followed, and nothing is remembered.

Keyboard and ARIA

  • Radios: Tab reaches the group, the arrow keys choose Auto, Light, Dark or High contrast. With luz.js, the cycle button moves to the next of the four with Enter or Space.
  • The legend and the labels are yours, in the page's language. The element adds no button, role or ARIA: the group is the fieldset and its radios.

Design

When to use

Use it when readers should not have to choose: the page follows their device, or the time of day, until they do.

  • by="system" for a site that reads best in the light or the dark the reader's device is in.
  • by="clock" for a site with a look for each part of the day, such as a venue or a weather page.

When not to use

Do not use it when the site has one look in one mode: a switcher with no Auto is core's.

  • Do not use by="clock" to promise the real sunrise: the hours are fixed.

Do and don't

Writing the content

Call the group “Color mode” and the choices “Auto”, “Light”, “Dark” and “High contrast”.

  • Say near the switcher what Auto follows: “Auto follows your device” or “Auto follows the time of day”.
