Each template is complete markup. Change the words and the links; keep the skip link, the single <h1> and the landmarks. The header is the site header.

They use only the classes of core and site. The blocks that fill a landing page, from the hero to the registration form, are in Landing page templates.

Landing page shell

The page of a product or an event: skip link, site header, one section with the page header and its actions, and a footer. The landing page blocks go inside <main>.

HTML 
<body class="cai-site-page cai-site-page--gradient">
  <a class="cai-site-skip-link" href="#main-content">Skip to main content</a>

  <header class="cai-site-header">
    <div class="cai-site-header__inner">
      <button class="cai-nav-toggle" type="button" popovertarget="site-nav" aria-label="Menu">

      </button>
      <a class="cai-site-header__brand" href="/">Acme</a>

Content page

An article or a documentation page: a sticky site header, the page header, then one <section> for each heading.

HTML 
<body class="cai-site-page">
  <a class="cai-site-skip-link" href="#main-content">Skip to main content</a>

  <header class="cai-site-header cai-site-header--sticky">…</header>

  <main id="main-content" class="cai-site-main o-container">
    <div class="cai-site-page-header">
      <h1 class="cai-site-page-header__title">Title of the article</h1>
      <p class="cai-site-page-header__lead">One sentence about what it covers.</p>
    </div>

    <section class="cai-site-section" aria-labelledby="first-title">
      <h2 id="first-title">First section</h2>
      <p>The text.</p>
    </section>
  </main>

  <footer class="cai-site-footer o-container">
    <p>Footer text</p>
  </footer>
</body>
