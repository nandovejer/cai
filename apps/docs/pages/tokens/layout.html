  • --cai-z-raised10Tooltips, sticky bars
  • --cai-z-overlay90Drawer backdrop
  • --cai-z-sidebar100Sidebar

  • --cai-sidebar-width256pxSidebar and app-shell column
  • --cai-content-max1100pxMaximum content width
  • --cai-bp-sm480pxSmall mobile
  • --cai-bp-md768pxTablet, sidebar collapse
  • --cai-bp-lg1024pxNarrow desktop
  • --cai-bp-xl1280pxStandard desktop
  • --cai-bp-2xl1440pxWide screen
  • --cai-font-headingvar(--cai-font-serif)Heading font family
  • --cai-text-controlvar(--cai-text-md)Form field text; --cai-text-base (16px) at 768px and below and on touch screens
  • --cai-scrollbar-size4pxScrollbar thickness

Ships with core, not with tokens. Breakpoints are reference values: CSS media queries cannot read custom properties.
