Themes and modes

A color mode changes how light or dark the page is; a theme changes its whole identity. You can combine them.

  • The three modes ship with the tokens: data-theme="light", "dark" and "high-contrast".
  • Two themes ship with core, each in a stylesheet of its own. Set the theme with data-theme and its mode with data-mode.
  • Minimalist (cai-theme-minimalist.css): one system sans throughout, warm neutrals.
  • Vejer (cai-theme-vejer.css): a reading theme inspired by Vejer de la Frontera. ET Book for running text and headings, whitewash and sandstone surfaces, iron-black text, sky-blue links and actions, and every link underlined.
<html data-theme="dark">

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/themes/cai-theme-vejer.min.css">
<html data-theme="vejer" data-mode="dark">
<html data-theme="minimalist" data-mode="high-contrast">

Every theme is measured by pnpm check:contrast in every mode: 4.5:1 for text, 3:1 for disabled text, borders and focus rings.

Make your own theme

A theme overrides semantic tokens, and may change the fonts, radii and shadows. It never changes the primitive colours or component CSS.

  • Give it a data-theme name of its own.
  • Check it against the same contrast minimums: CAI guarantees only the themes it ships.
[data-theme="my-brand"] {
  --cai-brand-primary: #0057ff;
  --cai-brand-hover: #0043c2;
  --cai-surface-page: #f8faff;
  --cai-text-primary: #0d1320;
  --cai-divider: #dbe3f2;
}
