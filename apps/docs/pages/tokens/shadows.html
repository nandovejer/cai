The higher the surface, the larger the shadow. Never use a shadow as the only edge of a surface: pair it with a border, because shadows disappear in forced colors. Shadows are the same in every mode.

  • --cai-shadow-sm: a card under the pointer.
  • --cai-shadow-md: tooltips and toasts.
  • --cai-shadow-lg: dialogs and the drawer.
  • --cai-shadow-icon: an icon over a picture, such as the play button on a video.
--cai-shadow-sm
0 1px 2px rgba(0,0,0,.15), 0 0 1px rgba(0,0,0,.1)
--cai-shadow-md
0 4px 8px rgba(0,0,0,.2), 0 2px 4px rgba(0,0,0,.12)
--cai-shadow-lg
0 12px 24px rgba(0,0,0,.24), 0 6px 12px rgba(0,0,0,.12)
--cai-shadow-icon
0 2px 8px rgba(0,0,0,.5)
