What a theme is

A color mode says how light or dark the page is: light, dark or high-contrast. A theme is a whole identity: colors, and optionally the fonts, radii and shadows. Every theme has the three modes.

  • CAI ships one look, Vejer, in the three modes. It is the default: with no attribute you get its light mode.
  • A theme of your own overrides semantic tokens only. It never changes a primitive, and it never touches a component's CSS.
  • You name it with data-theme and pick its mode with data-mode.

Make one, step by step

  1. Copy the template. It is @cai-ds/core/themes/_template.css. Every value in it is CAI's own, so it passes the contrast check before you change anything.
  2. Rename it. Replace my-brand, three times, by the name of your theme: lowercase letters, digits and hyphens.
  3. Change what you need. Start with the brand colors and the surfaces. Keep the three blocks complete: a token left out of the dark block takes its light value.
  4. Check it. Run the command in Check it until it passes.
  5. Load it after cai-tokens.css and cai.css, and set the attribute.
  6. List it in data-cai-themes, so the mode switcher remembers the visitor's choice.
HTML 
<link rel="stylesheet" href="cai-tokens.css">
<link rel="stylesheet" href="cai.css">
<link rel="stylesheet" href="my-brand.css">

<html lang="en" data-theme="my-brand" data-cai-themes="my-brand">
<!-- or, in its dark mode -->
<html lang="en" data-theme="my-brand" data-mode="dark" data-cai-themes="my-brand">

A small theme can be only the tokens that differ, in the first block: what you leave out takes CAI's value. Fill the dark and high-contrast blocks as well if you offer those modes.

CSS 
[data-theme="my-brand"] {
  --cai-brand-primary: #0057ff;
  --cai-brand-hover: #0043c2;
  --cai-brand-active: #003399;
  --cai-brand-fill: #0057ff;
  --cai-focus-ring: #0057ff;
  --cai-surface-page: #f8faff;
}

Check it

Shell 
npx @cai-ds/tokens check-contrast my-brand.css
  • It reads the theme as the browser would: the first block is the light mode, and each data-mode block lays on top of it.
  • The minimums are 4.5:1 for text, 3:1 for disabled text, borders, field borders and focus rings, in all three modes. Exit code 1 when a pair fails.
  • You can also paste the theme into the contrast check in the page.
  • CAI guarantees only what it ships. Your theme is as accessible as this check says, and no more.

Layers, modes and scope

  • Layers. Put the theme in @layer cai.themes to keep it below your own CSS, or leave it unlayered to win over all of CAI. Either way it wins over cai.tokens. The layers page has the order.
  • One zone. data-theme works on any element: the theme applies to that element and what is inside it. A date or time picker and a select take their color scheme from an ancestor data-theme, so for those put the attribute on <html>.
  • Forced colors. A reader who forces colors sees system colors, not your theme. Nothing to do: the components handle it.
  • Print. The cai.print layer sets paper colors whatever the theme.
  • The OS preference. With no stored choice and no attribute, the page is light. A page that wants to follow prefers-color-scheme sets data-theme itself.

Limits

  • One theme at a time on an element. Mix a theme and a mode, not two themes.
  • The mode switcher knows only the names in data-cai-themes: a name that is not listed works as an attribute, and is not remembered.
  • light-dark() is not used: it is not Baseline Widely available before 2026-11-13.
