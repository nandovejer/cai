# Safari and Firefox review ledger

What is waiting for a review in Safari and Firefox (**Open**), and the history of what has been reviewed (**Closed**, **Not verified**). The Playwright projects `firefox` and `webkit` and the reviews themselves are run by the maintainer before a release (AGENTS.md section 6); everyone else can help by testing one row and writing what they see.

Rows before 2026-10-14 name the agents by their old names: front-safari is safari-reviewer, front-firefox is firefox-reviewer, frontend is frontend-engineer.

A row is closed only when **both** browsers have reviewed it: remove it from "Open" and add it to "Closed" with the date and the result.

## Open

One row is one `needs-browser-review` issue: the issue repeats the Scope, the Files and what to look at, and says which browser is missing. The `security-auditor` agent reads this section, those issues and the maintainer's private list before it gives an OK; it gives none while a row in its scope is open. Everything below was checked in Chromium (and in Chromium with JavaScript off). On 2026-10-16 Firefox 155 (Gecko, Linux) reviewed every row and the fixes it asked for; what is left is Safari, whose first review is done and whose fixes are still to be re-checked.
