        Light, usable & zero-dependency

        LUZ، نظام تصميم للإنسان، جاهز للذكاء الاصطناعي.

        رموز التصميم وCSS وقليل من JavaScript الخالصة، مبنية على ما يفعله المتصفح أصلًا. كل مكوّن يعمل قبل تحميل JavaScript، في الوضع الفاتح والداكن والتباين العالي.

        نحب التطوير الموجَّه بالاختبارات: كل تغيير يبدأ باختبار فاشل.

        اقرأ التوثيق، باللغة الإنجليزية اعرض الشيفرة على GitHub

        الضوء حيث أنت

        عند تفعيل JavaScript، يُرسم هنا ضوء ساعتك.

        لماذا LUZ

        ثلاث كلمات، ووعد واحد.

        نظام تصميم للويب ينطلق من CSS ولا يحتاج إلى خطوة بناء. أنماط CSS الخاصة بك تغلب دائمًا، وJavaScript تحسين فقط، وكل صفحة تعمل قبل أن تُحمَّل.

        Light

        خفيف: CSS عادية ووحدات ES صغيرة من شبكة توصيل محتوى أو من npm. لا معالج مسبق ولا مترجم: ما تقرؤه في الملفات هو ما يشغّله المتصفح.

        هذه الصفحة تتبع ساعتك. انقر على ضوء لتستعير ساعة أخرى.

        Usable

        سهل الاستخدام: العناصر الأصلية أولًا، مثل dialog وpopover وdetails وrange وprogress. دعم لوحة المفاتيح والتركيز المرئي وتباين نص بنسبة 4.5:1 جزء من كل مكوّن، لا خيار إضافي.

        هذه كانت لوحة المفاتيح وحدها. اضغط Escape لإغلاق هذه الملاحظة.

        حلقة التركيز تأخذ لون إجراءات الصفحة، ولا تختفي أبدًا.

        Zero-dependency

        0

        اعتماديات وقت التشغيل. لا شيء تثبّته لتجربته، ولا إطار عمل تلاحق تحديثاته لسنوات.

        ماذا يتضمن

        اعتمده طبقةً طبقة.

        اتجاه واحد: كل حزمة تحتاج إلى ما تحتها ولا شيء مما فوقها، وتثبيتها يجلب ما تحتها. اختر المستوى الذي تحتاج إليه وتوقّف عنده.

        يعمل دون JavaScript

        ينطلق مما يفعله المتصفح أصلًا.

        كل مكوّن عنصر أصلي فوقه ورقة أنماط. عطّل JavaScript وستظل تُفتح وتُغلق وتنزلق وتتيح الاختيار.

        <details>

        ماذا تعني «بلا خطوة بناء»؟

        أن لا خطوة بين الملفات التي تقرؤها والصفحة التي يعرضها المتصفح. انسخها، واربطها، وانتهى الأمر.

        <dialog>

        يُفتح دون سكربت حيث يدعم المتصفح command؛ وفي غيره يفتحه سكربت صغير.

        مربع حوار أصلي

        ينتقل التركيز إليه، ويغلقه مفتاح Escape، ويُبقي المتصفح الصفحة التي خلفه بعيدة عن المتناول. لم تكتب أي مكتبة شيئًا من ذلك.

        popover

        تُغلق بالنقر خارجها وتظهر في الطبقة العليا، دون صراع مع z-index. المتصفح يتولى ذلك.

        <input type="range">

        <progress>

        الطباعة

        صُمّم ليُقرأ.

        خط ET Book للنص والعناوين اللاتينية، مستضاف ذاتيًا ومرخَّص بترخيص MIT. وخطوط النظام لعناصر التحكم والتسميات والشيفرة، وللعربية.

        الضوء هو المادة الأولى للصفحة. وكل ما عداه يوضع فيه.

        البدء

        وسم link واحد لكل طبقة.

        اختر مستوى، وانسخ المقتطف، وانشر. ثبّت رقم إصدار محددًا ما دام LUZ في مرحلة تجريبية.

        من شبكة توصيل محتوى 
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/tokens@0.0.0/dist/luz-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/core@0.0.0/dist/luz.min.css">

<button class="luz-btn luz-btn--primary">حفظ التغييرات</button>
<span class="luz-tag luz-tag--green luz-tag--dot">منشور</span>

        وهذه نتيجته

        منشور
        من npm 
        npm install @luz-ds/tokens @luz-ds/core

import "@luz-ds/tokens/css";
import "@luz-ds/core/css";
import "@luz-ds/core";

        ثم اكتب HTML. ‏<button class="luz-btn"> زر. ‏<dialog class="luz-modal"> مربع حوار. هذه هي الفكرة كلها.

        يناسبك

        • مواقع المحتوى والتوثيق والخدمات العامة التي يجب أن تستوفي WCAG 2.2 AA.
        • الصفحات التي تُولَّد على الخادم والمواقع الثابتة، بأي لغة برمجة للخادم.
        • الفرق التي تريد أن تقرأ CSS الخاص بها وتملكه.

        لا يناسبك

        • تحتاج إلى مكونات React أو Vue جاهزة.
        • تحتاج إلى جدول بيانات متقدم أو رسوم بيانية أو أداة لاختيار نطاق تواريخ: لا يوفّر LUZ أيًّا منها.
        • تحتاج إلى واجهة برمجية مستقرة اليوم: LUZ في مرحلة تجريبية، وقد تتغير الأسماء.
