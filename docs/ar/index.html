        Light, Usable & Zero-dependency

        LUZ، نظام تصميم أصلي ومنسّق، مبني لإمكانية الوصول.

        نظام تصميم للويب ينطلق من CSS ولا يحتاج إلى خطوة بناء. ثلاثة أوضاع للألوان، وCSS الخاص بك يغلب دائمًا، وJavaScript تحسينًا فقط.

        ابدأ الآن تصفّح المكونات

        لماذا تستخدم الفرق LUZ

        للمواقع والأدوات التي يجب أن تعمل للجميع، على أي جهاز، لسنوات، دون إطار عمل تضطر إلى مواكبته.

        • 01

          يعمل دون JavaScript

          المكونات عناصر HTML أصلية: <dialog> و<details> وعناصر التحكم في النماذج والنوافذ المنبثقة. ولا تضيف JavaScript إلا لمسات تحسين، لذلك تظل الصفحات تعمل حين يتعطل نص برمجي.

        • 02

          مصمَّم لإمكانية الوصول

          دعم لوحة المفاتيح، والتركيز المرئي، وتباين النص بنسبة 4.5:1، ووضع التباين العالي جزء من كل مكوّن، وتُشغَّل فحوص آلية مع كل تغيير. ويذكر بيان إمكانية الوصول، باللغة الإنجليزية، ما لم يُختبر بعد، بما في ذلك قارئات الشاشة.

        • 03

          لا شيء لتثبيته كي تجربه

          CSS عادي ووحدات ES صغيرة من شبكة CDN أو من npm. بلا معالج مسبق، وبلا مترجم، وبلا اعتماديات: ما تقرؤه في الملفات هو ما يشغّله المتصفح.

        شاهده وهو يعمل

        هذا هو الإعداد كله. والنتيجة أدناه يرسمها CSS نفسه.

        الإعداد كله 
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/tokens@0.1.0/dist/luz-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/core@0.1.0/dist/luz.min.css">

<button class="luz-btn luz-btn--primary">حفظ التغييرات</button>
<span class="luz-tag luz-tag--green luz-tag--dot">منشور</span>

        يتطلب tokens

        اختره إذا كنت تبني صفحات أو تطبيقًا وتستخدم تخطيط صفحاتك الخاص.

        • كل شيء في طبقة تتالٍ واحدة، luz: أنماط CSS الخاصة بك تتقدّم دون !important
        ثبّت المستوى 2 اعرض المكونات

        المستوى 3 Tokens + Core + Site

        يتطلب core وtokens

        اختره إذا كان موقعك يحتاج إلى بحث أو شريط لملفات تعريف الارتباط أو أكثر من لغة. هذه الصفحة مبنية بهذا المستوى.

        يضيف إلى المستوى 2

        • الموافقة على ملفات تعريف الارتباط: شريط ثابت أسفل النافذة لا يغطي شيئًا
        • قوائم فرعية لروابط الترويسة، وشريط إعلان فوقها
        • مبدّل اللغة
        • البحث في الموقع، مع JavaScript اختيارية
        ثبّت المستوى 3 اعرض الأنماط

        التالي: حزمة لنوع موقعك

        تُبنى فوق site حزم لنوع واحد من المواقع. ثبّت الحزمة العليا: فهي تجلب كل ما تحتها.

        • cms: مدونة أو صحيفة أو أي نظام لإدارة المحتوى، بأي تقنية. ترويسة المقال وقوائم التدوينات وفهرس المقال وبطاقة الكاتب.
        • landing: صفحة هبوط. شبكة الميزات والمتحدثون ودعوات الإجراء.
        • app: تطبيق ويب. الترويسة مع البحث والحساب، ولوحة معلومات من اللوحات، فوق الشريط الجانبي في core.
        tokens → core → site ─┬─ cms
                      ├─ landing
                      └─ app

        متى يناسبك LUZ

        يناسبك

        • مواقع المحتوى والتوثيق والخدمات العامة التي يجب أن تستوفي WCAG 2.2 AA.
        • الصفحات التي تُولَّد على الخادم والمواقع الثابتة، بأي لغة برمجة للخادم.
        • الفرق التي تريد أن تقرأ CSS الخاص بها وتملكه.

        لا يناسبك

        • تحتاج إلى مكونات React أو Vue جاهزة.
        • تحتاج إلى جدول بيانات متقدم أو رسوم بيانية أو أداة لاختيار نطاق تواريخ: لا يوفّر LUZ أيًّا منها.
        • تحتاج إلى واجهة برمجية مستقرة اليوم: LUZ في مرحلة تجريبية، وقد تتغير الأسماء.
