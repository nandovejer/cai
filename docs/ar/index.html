        البدء رموز التصميم Core Platform عناصر HTML إمكانية الوصول

        Consistent Adaptive Identity

        CAI، نظام تصميم أصلي ومنسّق، مبني لإمكانية الوصول.

        نظام تصميم للويب ينطلق من CSS ولا يحتاج إلى خطوة بناء. ثلاثة أوضاع للألوان، وCSS الخاص بك يغلب دائمًا، وJavaScript تحسينًا فقط.

        ابدأ الآن تصفّح المكونات

        لماذا تستخدم الفرق CAI

        للمواقع والأدوات التي يجب أن تعمل للجميع، على أي جهاز، لسنوات، دون إطار عمل تضطر إلى مواكبته.

        • 01

          يعمل دون JavaScript

          المكونات عناصر HTML أصلية: <dialog> و<details> وعناصر التحكم في النماذج والنوافذ المنبثقة. ولا تضيف JavaScript إلا لمسات تحسين، لذلك تظل الصفحات تعمل حين يتعطل نص برمجي.

        • 02

          مصمَّم لإمكانية الوصول

          دعم لوحة المفاتيح، والتركيز المرئي، وتباين النص بنسبة 4.5:1، ووضع التباين العالي جزء من كل مكوّن، وتُشغَّل فحوص آلية مع كل تغيير. ويذكر بيان إمكانية الوصول، باللغة الإنجليزية، ما لم يُختبر بعد، بما في ذلك قارئات الشاشة.

        • 03

          لا شيء لتثبيته كي تجربه

          CSS عادي ووحدات ES صغيرة من شبكة CDN أو من npm. بلا معالج مسبق، وبلا مترجم، وبلا اعتماديات: ما تقرؤه في الملفات هو ما يشغّله المتصفح.

        شاهده وهو يعمل

        هذا هو الإعداد كله. والنتيجة أدناه يرسمها CSS نفسه.

        الإعداد كله 
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css">

<button class="cai-btn cai-btn--primary">حفظ التغييرات</button>
<span class="cai-tag cai-tag--green cai-tag--dot">منشور</span>

        ثبّت المستوى 3 اعرض الأنماط

        متى يناسبك CAI

        يناسبك

        • مواقع المحتوى والتوثيق والخدمات العامة التي يجب أن تستوفي WCAG 2.2 AA.
        • الصفحات التي تُولَّد على الخادم والمواقع الثابتة، بأي لغة برمجة للخادم.
        • الفرق التي تريد أن تقرأ CSS الخاص بها وتملكه.

        لا يناسبك

        • تحتاج إلى مكونات React أو Vue جاهزة.
        • تحتاج إلى جدول بيانات متقدم أو رسوم بيانية أو أداة لاختيار نطاق تواريخ: لا يوفّر CAI أيًّا منها.
        • تحتاج إلى واجهة برمجية مستقرة اليوم: CAI في مرحلة تجريبية، وقد تتغير الأسماء.
