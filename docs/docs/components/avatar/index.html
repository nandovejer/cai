        Avatar

        components/avatar.css

        Shows who a person or a team is, with their initials, in three sizes.

        Example

        AB CD EF

        Known issues

        None known.

        Code Design

        Code

        Copy the markup

        HTML 
        <span class="cai-avatar cai-avatar--md" role="img" aria-label="Carlos Díaz">CD</span>

        Next to the person's name, the avatar repeats it: hide it instead.

        HTML 
        <span class="cai-avatar cai-avatar--sm" aria-hidden="true">CD</span> Carlos Díaz

        Variants and options

        Pick one size modifier. Without one, the avatar has no size of its own.

        ClassSize
        .cai-avatar--sm
        24 × 24 px, extra-small text
        .cai-avatar--md
        36 × 36 px, small text
        .cai-avatar--lg
        48 × 48 px, base text

        How it works

        An inline box that centres its text, styled by components/avatar.css. No JavaScript.

        • The initials are set in the mono font, in capitals (text-transform: uppercase).
        • The colours are the brand tint and the brand text colour, in every mode.

        Without JavaScript

        Nothing changes: the avatar is HTML and CSS only.

        Keyboard and ARIA

        An avatar is not interactive and takes no focus.

        • On its own, it is an image: role="img" and an aria-label with the full name, so a screen reader does not spell out the initials.
        • Next to the name, it is decoration: aria-hidden="true".
        • Inside a link or a button, the control's text names it; hide the avatar.

        Contrast and focus are in the Design tab.

        Design

        When to use

        Use an avatar to identify a person or an account where space is tight, such as a list of members or the author of a comment.

        When not to use

        Do not use an avatar as the only way to tell people apart.

        • Two people can share initials: show the name as text nearby.
        • For a status or a category, use a tag.

        Do and don't

        Writing the content

        Two initials, from the name the person uses.

        • The accessible name is the full name, never the initials.
        • Use the same size for every avatar in one list.

        Contrast and focus

        The initials are brand text on the subtle brand tint.

        PartColour on backgroundLightDarkHigh contrastNeeds
        Initials
        --cai-brand-primary on --cai-brand-subtle over --cai-surface-page
        5.3:1
        7.1:1
        13.6:1
        4.5:1

        Measured from the token values of each mode, rounded down. Needs is the WCAG 2.2 AA minimum: 4.5:1 for text, 3:1 for focus rings, borders and icons.

        • Focus: the avatar takes none. If it is part of a link, the link's ring outlines it.
        • Not colour alone: the initials and the accessible name carry the person; the colour is the same for everyone.

        Tokens it uses

        The 6 tokens that components/avatar.css reads, by family. Each family links to its page, with the values in every mode. In Figma they are variables with the same names: see Tokens in Figma.

        Color
        --cai-brand-primary, --cai-brand-subtle
        Typography
        --cai-font-mono, --cai-text-base, --cai-text-sm, --cai-text-xs
