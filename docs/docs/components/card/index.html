        Known issues

        Code Design

        Code

        Copy the markup

        HTML 
        <article class="cai-card">
  <h3 class="cai-card__title">Database</h3>
  <p class="cai-card__body">48 active connections.</p>
</article>

        Variants and options

        There are no modifiers: one card, three classes.

        ClassWhat it does
        .cai-card
        The surface: border, padding, a shadow on hover
        .cai-card__title
        Base size, semibold, primary text colour
        .cai-card__body
        Medium size, secondary text colour

        How it works

        A container styled by components/card.css. No JavaScript.

        • Use any element: <article> for a self-contained item, <div> for a group of facts, <li> inside a list of cards.
        • The title class goes on the heading level that fits the page outline.
        • To lay cards out, use the grid object or the feature grid.

        Without JavaScript

        Nothing changes: a card is HTML and CSS.

        Keyboard and ARIA

        A card is not interactive and takes no focus.

        • Links and buttons inside it keep their own behaviour.
        • To link a whole card, put the link on the title text, not around the card: one tab stop, and a name that is the title.

        Contrast and focus are in the Design tab.

        Design

        When to use

        Use a card to group a small set of facts that read as one unit, often in a grid of similar items.

        When not to use

        Do not use a card to box content that is not a separate thing.

        • For rows of records with the same attributes, use a table.
        • For a message about the page, use an alert.
        • Do not put a card inside a card.

        Do and don't

        Writing the content

        A short noun as the title, then one or two lines.

        • No full stop on the title.
        • Keep cards in one group parallel: the same kind of title, the same length of body.

        Contrast and focus

        The title is primary text and the body secondary text, on the card surface.

        PartColour on backgroundLightDarkHigh contrastNeeds
        Title
        --cai-text-primary on --cai-surface
        19.3:1
        16.8:1
        21.0:1
        4.5:1
        Body
        --cai-text-secondary on --cai-surface
        9.0:1
        11.9:1
        19.3:1
        4.5:1

        Measured from the token values of each mode, rounded down. Needs is the WCAG 2.2 AA minimum: 4.5:1 for text, 3:1 for focus rings, borders and icons.

        • Focus: the card takes none; the links and buttons inside keep their own ring.
        • Edges: the border (--cai-divider) is decorative and has no minimum: the content and the space around it group the card.

        Tokens it uses

        The 14 tokens that components/card.css reads, by family. Each family links to its page, with the values in every mode. In Figma they are variables with the same names: see Tokens in Figma.

        Color
        --cai-divider, --cai-outline, --cai-surface, --cai-text-primary, --cai-text-secondary
        Spacing and sizing
        --cai-space-2xs, --cai-space-md, --cai-space-sm
        Typography
        --cai-text-base, --cai-text-md
        Shadows
        --cai-shadow-sm
        Motion
        --cai-duration-base, --cai-duration-fast, --cai-easing-enter
