        Copy button

        components/copy-btn.css JS: clipboard.js

        Copies a command or a value to the clipboard, and says it did.

        Example

        var(--cai-brand-primary)

        The button copies the text of its data-copy attribute.

        Known issues

        The Clipboard API needs a secure context (https, or localhost while you develop). Elsewhere the copy fails: the failure is announced, and the text can still be selected and copied by hand.

        Code Design

        Code

        Copy the markup

        HTML 
        <code class="cai-code-inline">npm install @cai-ds/core</code>
<button class="cai-copy-btn" type="button" data-copy="npm install @cai-ds/core" aria-label="Copy the install command">Copy</button>
        JS 
        import { initCopyButtons } from "@cai-ds/core/clipboard";
initCopyButtons();

        Variants and options

        One class and one attribute. The look does not change.

        Class or attributeEffect
        .cai-copy-btn
        Small mono button, 24 px high; hidden until the script runs
        data-copy
        The exact text to copy
        .is-copied
        Set by the script for about a second after a copy: success colour, label "Copied"

        How it works

        A native <button>, styled by components/copy-btn.css and wired by clipboard.js.

        • initCopyButtons() listens for clicks on any .cai-copy-btn and copies its data-copy. cai.js runs it.
        • For about a second the label reads "Copied", then goes back.
        • A polite live region says "Copied to clipboard", or that the copy failed. The texts come from i18n.js, in the language of the page.
        • copyToClipboard(text, el) does the same for your own controls.

        Without JavaScript

        The button is hidden, because it would do nothing. The text it copies stays on the page, so the reader selects and copies it.

        Keyboard and ARIA

        Tab reaches the button; Enter or Space copies. Focus stays on the button.

        • The visible label is "Copy"; the aria-label starts with it and says what is copied: "Copy the install command".
        • The result is announced in a polite live region shared by every copy button.

        Contrast and focus are in the Design tab.

        Design

        When to use

        Use a copy button for a short string the reader will paste somewhere else: a command, a token name, a key.

        When not to use

        Do not use a copy button where selecting the text is just as easy, or as the only way to get the content.

        • For a shell command with its prompt, use a command block.
        • For long text, show it in a code block the reader can select.

        Do and don't

        Writing the content

        Keep the visible label "Copy", and name what it copies in the accessible name.

        • Start the accessible name with the visible word: "Copy the install command".
        • Copy exactly what is shown, without a prompt sign or extra spaces.
