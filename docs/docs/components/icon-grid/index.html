Icon grid

components/icon-grid.css JS: clipboard.js

A grid of icons with their names, to browse and copy.

On this page
  • Example
  • Known issues
  • When to use
  • When not to use
  • How it works

Example

  • Plus
  • Check
  • Arrow
  • Close

Each icon has a button that copies its SVG. CAI ships the grid, not an icon set: these four are local to this page.

Known issues

None known.

When to use

To let readers browse and copy a set of icons.

When not to use

Do not use icons as the only label of an action.

How it works

A list of icons. Each item shows the icon, its name and a native copy button with the SVG in data-copy. Without JavaScript the copy buttons are hidden and the list still shows every icon and name. CAI ships the grid, not an icon set.

Content guidance

Each item shows the icon name in text. Decorative icons are aria-hidden.

Keyboard and ARIA

Tab to a copy button, Enter or Space to copy. Each button is named by its own text and the icon name (aria-labelledby), for example "Copy SVG Plus". The result is announced in a polite live region.
