# Components

Every core component, grouped by task, with a live example, the markup to copy and when to use it.

A **component** is one reusable piece, almost always tied to one HTML element: a button, a field, a table. A **pattern** combines components to do a product task, such as a page shell or a site search; patterns are in [Site](https://nandovejer.github.io/luz/docs/site/).
