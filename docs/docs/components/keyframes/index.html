        Keyframes

        components/_animations.css

        Five shared animations for your own components, which stop when the reader asks for reduced motion.

        Reduced motion is on, so the animations do not run.

        • cai-spin
        • cai-shimmer
        • cai-pulse
        • Aacai-slide-up

        A fifth keyframe, cai-fade-in, opens the modal.

        Use a keyframe

        Name the keyframe in your own animation, and take its duration from a motion token.

        CSS 
        .panel[open] {
  animation: cai-slide-up var(--cai-duration-base) var(--cai-easing-enter);
}
        • Under reduced motion every --cai-duration-* token is 0s, so the animation does not run and the element shows in its final state.
        • A hard-coded duration ignores reduced motion: never write one.
        • Do not loop an animation for ever: stop it when the task ends.
        KeyframeWhat it does
        cai-spin
        One full turn, for a loading indicator
        cai-shimmer
        Moves a background gradient across, for a loading placeholder
        cai-pulse
        Grows and fades out, then back, to draw the eye once
        cai-slide-up
        Fades in while rising 8 px, for something that appears
        cai-fade-in
        Fades in, used by the modal and its backdrop
