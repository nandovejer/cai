        Media object

        A fixed item beside content that takes the remaining width.

        .o-shell, .o-main and .o-container are page-level: this page uses them.

        Pick an object

        Objects only lay things out: no colour, no type. Spacing comes from the space tokens.

        ClassWhat it does
        .o-stack
        A column, 12 px between items
        .o-row
        A row that wraps, items centred vertically, 12 px between them
        .o-grid
        A grid with 16 px gaps; set the columns with your own grid-template-columns, or with one of the modifiers below
        .o-grid--auto
        As many equal columns as fit, none narrower than --cai-grid-min (16 rem by default): the grid reflows by itself and needs no breakpoint
        .o-grid--2, .o-grid--3, .o-grid--4
        That many equal columns above 768 px; one column at 768 px and below
        .o-media, .o-media__body
        A fixed item, such as an avatar, beside content that takes the remaining width
        .o-container
        The content width (--cai-content-max, 1100 px) and page padding; less padding at 640 px and below
        .o-shell
        The app layout: a sidebar column (--cai-sidebar-width) beside the main area, a footer across the bottom; one column at 768 px and below
        .o-main
        The main area inside .o-shell

        The grid

        CAI has no 12-column system: a content grid is a handful of equal columns, and .o-grid draws them. Use .o-grid--auto when the items decide how many fit, such as cards; use .o-grid--2 to --4 when the number is part of the design.

        HTML 
        <!-- as many columns as fit, each at least 16 rem -->
<div class="o-grid o-grid--auto">…cards…</div>

<!-- at least 12 rem: set the property in your own CSS -->
<div class="o-grid o-grid--auto gallery">…</div>
<style>.gallery { --cai-grid-min: 12rem; }</style>

<!-- three columns above 768 px, one below -->
<div class="o-grid o-grid--3">…</div>
        • Items keep their source order: the grid reorders nothing, so reading order and tab order are the page's.
        • Columns are minmax(0, 1fr), so a long word or a wide table inside an item cannot push the grid wider than its container.
        • For a layout that depends on the width of a card and not of the window, put the grid in a container and size the items there; the objects do not read the container.

        Copy the markup

        HTML 
        <div class="o-media">
  <span class="cai-avatar cai-avatar--md" aria-hidden="true">AB</span>
  <div class="o-media__body">
    <p>Ana Belén</p>
  </div>
</div>
        HTML 
        <body class="o-shell">
  <nav class="cai-sidebar" aria-label="Main">…</nav>
  <main class="o-main" id="main-content">
    <div class="o-container">…</div>
  </main>
  <footer>…</footer>
</body>

        The footer is a plain <footer>, which core places across the bottom: nothing here needs site. To give it the look of site's footer, use .cai-site-footer on it. For whole pages without a sidebar, the page shell of site does the same job. What each package needs lists every piece.
