        Example

        Delete this draft?

        You cannot undo this. The draft and its comments are deleted.

        A native <dialog>. Escape closes it and focus goes back to the button that opened it. Nothing is deleted here.

        Known issues

        Some supported browsers do not have the command and commandfor attributes yet. In those browsers, with JavaScript off, the open button does nothing. Give the reader another way to the same action.

        Code Design

        Code

        Copy the markup

        HTML 
        <button class="cai-btn cai-btn--primary" type="button" commandfor="rename" command="show-modal">Rename project</button>

<dialog class="cai-modal" id="rename" aria-labelledby="rename-title">
  <div class="cai-modal__header">
    <button class="cai-modal__close" type="button" commandfor="rename" command="close" aria-label="Close dialog">×</button>
    <h2 class="cai-modal__title" id="rename-title">Rename project</h2>
  </div>
  <form method="dialog">
    <div class="cai-modal__body">
      <div class="cai-field">
        <label class="cai-field__label" for="rename-name">New name</label>
        <input class="cai-input" id="rename-name" type="text" autofocus>
      </div>
    </div>
    <div class="cai-modal__footer">
      <button class="cai-btn cai-btn--ghost" type="button" commandfor="rename" command="close">Cancel</button>
      <button class="cai-btn cai-btn--primary" value="rename">Rename project</button>
    </div>
  </form>
</dialog>
        JS 
        import { initModals } from "@cai-ds/core/modal";
initModals();

        Variants and options

        One size and no modifiers: up to 600 px wide and 90 % of the viewport high, scrolling inside when the content is longer.

        Class or attributeWhat it does
        .cai-modal
        The dialog surface, with a dimmed and slightly blurred backdrop
        .cai-modal__header, __title
        The title row, with a rule under it
        .cai-modal__close
        The × button, at the end of the title row, 28 px at least
        .cai-modal__body
        The content
        .cai-modal__footer
        The buttons, at the end of the row, with a rule above them
        command="show-modal", command="close"
        Open and close the dialog named in commandfor

        How it works

        A native <dialog>, styled by components/modal.css and opened as a modal.

        • The browser does the hard part: the page behind is inert, focus stays inside, Escape closes, and focus goes back to the opener.
        • Buttons open and close it with command and commandfor, with no script.
        • initModals() from modal.js handles the same two commands in browsers that do not support them yet, and does nothing in the others. cai.js runs it.
        • A <form method="dialog"> inside closes the dialog when it is sent, and its returnValue is the value of the button pressed.

        Without JavaScript

        In browsers that support command, everything works. In the others the open button does nothing: see Known issues.

        Keyboard and ARIA

        Tab and Shift+Tab move inside the dialog only; Escape closes it.

        • On open, focus goes to the first focusable element, or to the one with autofocus.
        • Name the dialog with aria-labelledby pointing at its title.
        • The × button needs aria-label="Close dialog": its text is a symbol.

        Contrast and focus are in the Design tab.

        Design

        When to use

        Use a modal to ask for a decision or a short input that must be settled before the reader goes on.

        • To confirm an action that cannot be undone.
        • To ask for one or two values, such as a new name.

        When not to use

        Do not use a modal for something the reader can ignore or come back to.

        • For information about the page, use an alert.
        • For a confirmation that needs no answer, use a toast.
        • For a long form, use its own page.
        • Never open a modal when the page loads.

        Do and don't

        Writing the content

        The title asks the question or names the task: "Delete this draft?"

        • The body says what happens, in one or two sentences.
        • The main button repeats the action: "Delete draft". The other one is "Cancel".
        • Never "OK", "Yes" or "Confirm".

        Measured from the token values of each mode, rounded down. Needs is the WCAG 2.2 AA minimum: 4.5:1 for text, 3:1 for focus rings, borders and icons.

        • Focus: it moves into the dialog when it opens and back to the button that opened it when it closes. The close button has a 2 px --cai-focus-ring outline, 2 px outside.
        • Edges: the dialog has a border and a shadow, so it stays apart from the page in forced colors too.
        • Target: the close button is at least 28 px square.
