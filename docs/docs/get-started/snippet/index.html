        Get started

        Choose your snippet

        Pick what you are building and how you load it, then copy the lines. The CDN lines carry integrity hashes computed from the published files.

        Every snippet loads tokens first, then core, then the package for your kind of site, in the order the cascade layers expect. The site package is optional for a landing page, a blog and an application, so its lines are marked and safe to delete.

        For the level-by-level explanation, read Install LUZ; for a build tool, With a bundler or framework.

        Lazy chunks

        Core and site load some files only when the page needs them: a sortable table, a timeline, a MIDI player, a page in Spanish, the search, the cookie banner. A hash on a script covers that file only, so a chunk needs its own hash. The way to give it one in every browser is an import map with an integrity section, placed before the first module script: the browser then checks each chunk when the script imports it, and a file with a wrong hash does not run.

        Safari and Firefox do not use the integrity of a <link rel="modulepreload"> to block a file, so it is a performance hint only: use it, if you like, to fetch a chunk earlier, but do not rely on it as the check. The import map below lists every chunk. Keep only the lines for what the page has, as the rows say, because a hash for a file the page never loads does nothing.

        HTML 
        <script type="importmap">
{
  "integrity": {
    "https://cdn.jsdelivr.net/npm/@luz-ds/core@0.0.0/dist/midi.min.js": "sha384-1/jMwUxslzdTelDpKZnWaNfcn11b+/hcvpxbX+SLH35MVtexPnyFKINInbVxwzV8",
    "https://cdn.jsdelivr.net/npm/@luz-ds/core@0.0.0/dist/table-sort.min.js": "sha384-R+imdkLSyzPq7oSWCtDRr7lxmMxpy4ukmtJG2wc+DtF7AfPuRnKbaMxnSEPQrMFi",

        Verify a hash yourself

        Every hash on this page is computed from the file that the package publishes, when the documentation is built. To check one, download the file you load and hash it the same way:

        Shell 
        curl -s <url of the file> | openssl dgst -sha384 -binary | openssl base64 -A

        The result, after sha384-, is the value of integrity. If it differs from the page, do not load the file: the version in the URL or the file itself has changed.
