# Choose your snippet

Pick what you are building and how you load it, then copy the lines. The CDN lines carry integrity hashes computed from the published files.

Every snippet loads tokens first, then core, then the package for your kind of site, in the order the [cascade layers](https://nandovejer.github.io/luz/docs/get-started/layers/) expect. The site package is optional for a landing page, a blog and an application, so its lines are marked and safe to delete. For the level-by-level explanation, read [Install LUZ](https://nandovejer.github.io/luz/docs/get-started/); for a build tool, [With a bundler or framework](https://nandovejer.github.io/luz/docs/get-started/bundler/).
