Words and phrases inside a block: emphasis, abbreviations, code, time, annotations. Pick the element for its meaning, then let the style follow.

<a>

MDN reference for the a element

A link to another page, a file, a place on the same page or an email address. CAI colors it with the brand color and underlines it on hover, with a visible focus ring.

Read the full reference before you start.

HTML 
<p>Read the <a href="#">full reference</a> before you start.</p>

Styled by elements/inline.css, with no class.

<abbr>

MDN reference for the abbr element

A short form of a word or phrase, such as HTML. Put the full form in the title attribute; with a title, it gets a dotted underline and a help cursor.

CAI uses plain CSS.

HTML 
<p>CAI uses plain <abbr title="Cascading Style Sheets">CSS</abbr>.</p>

Styled by elements/inline.css, with no class.

<b>

MDN reference for the b element

Makes a few words stand out in bold without saying they matter more, such as the option names in a how-to. If they do matter more, use strong.

The ET Book typeface is used for headings.

HTML 
<p>The <b>ET Book</b> typeface is used for headings.</p>

Styled by elements/inline.css, with no class.

<bdi>

MDN reference for the bdi element

Keeps text whose writing direction you cannot know in advance, such as a user name that may be Arabic or Hebrew, from scrambling the text around it.

User إيان scored 90 points.

HTML 
<p>User <bdi>إيان</bdi> scored 90 points.</p>

CAI adds no style: the browser look is kept.

<bdo>

MDN reference for the bdo element

Forces its text to run left to right or right to left, as set by dir, whatever the characters are. You rarely need it: bdi covers most cases.

This text runs right to left.

HTML 
<p><bdo dir="rtl">This text runs right to left.</bdo></p>

CAI adds no style: the browser look is kept.

<br>

MDN reference for the br element

A line break that is part of the content, as in a postal address or a poem. Do not use it to add space.

Line one
Line two
Line three

HTML 
<p>Line one<br>Line two<br>Line three</p>

CAI adds no style: the browser look is kept.

<cite>

MDN reference for the cite element

The title of a book, film, paper, song or other work you mention. Not for the name of a person.

The Design of Everyday Things is a book by Don Norman.

HTML 
<p><cite>The Design of Everyday Things</cite> is a book by Don Norman.</p>

CAI adds no style: the browser look is kept.

<code>

MDN reference for the code element

A short piece of code, a file name or a command inside a sentence. CAI sets it in the mono font at a readable size.

Use var(--cai-brand-primary) for links.

HTML 
<p>Use <code>var(--cai-brand-primary)</code> for links.</p>

Styled by elements/inline.css, with no class. For a block of code use pre.cai-code-block; .cai-code-inline adds a chip look to inline code.

<data>

MDN reference for the data element

Pairs visible text with a value for software, held in the value attribute, such as a product name with its code. For dates and times, use time.

CAI has three layers.

HTML 
<p>CAI has <data value="3">three</data> layers.</p>

CAI adds no style: the browser look is kept.

<dfn>

MDN reference for the dfn element

Marks a term at the place where the text explains what it means.

A design token is a named design decision, stored as a variable.

HTML 
<p>A <dfn>design token</dfn> is a named design decision, stored as a variable.</p>

Styled by elements/inline.css, with no class.

<em>

MDN reference for the em element

Puts stress on a word, the one you would say louder, which can change the meaning of the sentence. Browsers show it in italic.

Load the tokens before the core.

HTML 
<p>Load the tokens <em>before</em> the core.</p>

CAI adds no style: the browser look is kept.

<i>

MDN reference for the i element

Italic text with no extra stress, for words read in another voice: a phrase in another language, a character's inner voice. For stress, use em.

The result is ad hoc, not a rule.

HTML 
<p>The result is <i lang="la">ad hoc</i>, not a rule.</p>

CAI adds no style: the browser look is kept.

<kbd>

MDN reference for the kbd element

A key or other input the user should press or type, such as Ctrl + C. CAI draws it as a key cap.

Press Ctrl + K to open the command palette.

HTML 
<p>Press <kbd>Ctrl</kbd> + <kbd>K</kbd> to open the command palette.</p>

Styled by elements/inline.css, with no class.

<mark>

MDN reference for the mark element

Highlights text because it matters right now, such as the words that matched a search. It does not add importance: use strong for that.

Search results for tokens.

HTML 
<p>Search results for <mark>tokens</mark>.</p>

Styled by elements/inline.css, with no class.

<q>

MDN reference for the q element

A short quotation inside a sentence. The browser adds the quotation marks of the page language, so do not type your own.

As they say, less is more.

HTML 
<p>As they say, <q>less is more</q>.</p>

CAI adds no style: the browser look is kept.

<rp>

MDN reference for the rp element

Parentheses that appear around a ruby annotation only in browsers that cannot place it above the text.

漢(kan)字(ji)
HTML 
<ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp>字<rp>(</rp><rt>ji</rt><rp>)</rp></ruby>

CAI adds no style: the browser look is kept.

<rt>

MDN reference for the rt element

The text of a ruby annotation, such as how a character is pronounced. CAI keeps it above the 12px floor.

漢(kan)字(ji)
HTML 
<ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp>字<rp>(</rp><rt>ji</rt><rp>)</rp></ruby>

Styled by elements/inline.css, with no class.

<ruby>

MDN reference for the ruby element

Puts small notes above or beside characters, mostly to show how East Asian characters are read. Each note goes in an rt.

漢(kan)字(ji)
HTML 
<ruby>漢<rp>(</rp><rt>kan</rt><rp>)</rp>字<rp>(</rp><rt>ji</rt><rp>)</rp></ruby>

CAI adds no style: the browser look is kept.

<s>

MDN reference for the s element

Text that is no longer true or no longer applies, such as an old price. For a tracked removal, use del. CAI also tones it down to the secondary color.

$20 $15 this week.

HTML 
<p><s>$20</s> $15 this week.</p>

Styled by elements/inline.css, with no class.

<samp>

MDN reference for the samp element

Text a program printed, such as an error message or the output of a terminal command.

The console prints Layer "tokens" is missing.

HTML 
<p>The console prints <samp>Layer "tokens" is missing.</samp></p>

Styled by elements/inline.css, with no class.

<small>

MDN reference for the small element

Fine print: copyright lines, legal notes, disclaimers. CAI never sets it under the 12px floor.

Total: $15 Prices include VAT.

HTML 
<p>Total: $15 <small>Prices include VAT.</small></p>

Styled by elements/inline.css, with no class.

<span>

MDN reference for the span element

A plain inline wrapper that adds no meaning. Use it to hang a class or a lang attribute on a few words.

CAI is stable.

HTML 
<p>CAI is <span class="cai-tag cai-tag--green">stable</span>.</p>

CAI adds no style: the browser look is kept.

<strong>

MDN reference for the strong element

Words the reader must not miss: a warning, a key condition, a deadline. For stress that changes how a sentence reads, use em.

Warning: do not edit the dist folder.

HTML 
<p><strong>Warning:</strong> do not edit the dist folder.</p>

Styled by elements/inline.css, with no class.

<sub>

MDN reference for the sub element

Text set lower and smaller, such as the 2 in the formula for water. CAI keeps it from pushing the lines apart.

Water is H2O.

HTML 
<p>Water is H<sub>2</sub>O.</p>

Styled by elements/inline.css, with no class.

<sup>

MDN reference for the sup element

Text set higher and smaller, for powers, footnote numbers and the letters in 1st. CAI keeps it from pushing the lines apart.

E = mc2

HTML 
<p>E = mc<sup>2</sup></p>

Styled by elements/inline.css, with no class.

<time>

MDN reference for the time element

A date, a time or a duration. Put a form software can read in the datetime attribute, and write whatever suits the reader inside.

Released on 6 October 2026.

HTML 
<p>Released on <time datetime="2026-10-06">6 October 2026</time>.</p>

Styled by elements/inline.css, with no class.

<u>

MDN reference for the u element

An underline for a note that is not a link, such as a flagged spelling mistake. Readers take underlines for links, so use it sparingly.

This word is mispelled.

HTML 
<p>This word is <u>mispelled</u>.</p>

Styled by elements/inline.css, with no class.

<var>

MDN reference for the var element

The name of a variable in a formula or in code, such as x in an equation.

Solve x + y = 10.

HTML 
<p>Solve <var>x</var> + <var>y</var> = 10.</p>

Styled by elements/inline.css, with no class.

<wbr>

MDN reference for the wbr element

Tells the browser where it may wrap a long word or URL when it runs out of room. Nothing shows when the line does not wrap.

https://example.com/very/long/path

HTML 
<p style="max-inline-size: 12ch">https://<wbr>example.com/<wbr>very/<wbr>long/<wbr>path</p>

CAI adds no style: the browser look is kept.
