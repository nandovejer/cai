# Inline text

Mark up words and phrases inside a block: emphasis, abbreviations, code, time, notes. Pick the element for its meaning; the style follows.

- `<a>`
- `<abbr>`
- `<b>`
- `<bdi>`
- `<bdo>`
- `<br>`
- `<cite>`
- `<code>`
- `<data>`
- `<dfn>`
- `<em>`
- `<i>`
- `<kbd>`
- `<mark>`
- `<q>`
- `<rp>`
- `<rt>`
- `<ruby>`
- `<s>`
- `<samp>`
- `<small>`
- `<span>`
- `<strong>`
- `<sub>`
- `<sup>`
- `<time>`
- `<u>`
- `<var>`
- `<wbr>`
