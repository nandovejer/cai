Images and media

On this page
  • <area>
  • <audio>
  • <img>
  • <map>
  • <track>
  • <video>

Images, sound and video, plus the elements that add captions or make parts of an image clickable.

<area>

MDN reference for the area element

One clickable shape on an image map, with its own link and alt text. It always sits inside a map.

HTML 
<img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120" usemap="#d-areas">
<map name="d-areas">
  <area shape="rect" coords="20,20,100,100" href="#" alt="The square">
  <area shape="circle" coords="170,60,40" href="#" alt="The circle">
</map>

CAI adds no style: the browser look is kept.

<audio>

MDN reference for the audio element

Plays sound with the browser's own controls. Offer one source per file format, and put a link to the file inside for browsers that cannot play it.

HTML 
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
  Your browser does not support audio.
</audio>

Styled by elements/media.css, with no class. CAI makes the controls full width. The .cai-player component builds its own.

<img>

MDN reference for the img element

Shows an image. Always write alt: say what the image shows, or leave it empty when it is only decoration.

HTML 
<img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120">

Styled by elements/media.css, with no class. CAI keeps it inside its box and keeps the aspect ratio.

<map>

MDN reference for the map element

Turns parts of an image into links, with one area per clickable shape. Connect it to the img with usemap.

HTML 
<img src="shapes.svg" alt="A blue square and a grey circle" width="240" height="120" usemap="#d-map">
<map name="d-map">
  <area shape="rect" coords="20,20,100,100" href="#" alt="The square">
  <area shape="circle" coords="170,60,40" href="#" alt="The circle">
</map>

CAI adds no style: the browser look is kept.

<track>

MDN reference for the track element

A text file timed to an audio or video, such as captions, subtitles or chapter titles. It goes inside the audio or video element.

HTML 
<video controls preload="metadata" width="320" aria-label="A sun rises behind an arched window on a whitewashed wall. No sound.">
  <source src="video.mp4" type="video/mp4">
  <track kind="captions" srclang="en" label="English" src="captions.vtt" default>
</video>

CAI adds no style: the browser look is kept.

<video>

MDN reference for the video element

Plays video with the browser's own controls. Always give a text alternative, and captions when there is speech or other sound.

HTML 
<video controls preload="metadata" width="320" aria-label="A sun rises behind an arched window on a whitewashed wall. No sound.">
  <source src="video.mp4" type="video/mp4">
</video>

Styled by elements/media.css, with no class. CAI keeps it inside its box. The .cai-player component builds its own controls.
