        Page metadata

        On this page
        • <base>
        • <head>
        • <link>
        • <meta>
        • <style>
        • <title>

        Tell browsers, search engines and scripts about the page. Readers never see these elements, so the cards show the markup only.

        <base>

        MDN reference for the base element

        Changes the starting point of every relative URL on the page, and can set a default target for links. Use at most one, and place it before any tag that has a URL.

        Markup only: this element is not rendered.

        HTML 
        <base href="https://example.com/app/" target="_blank">

        CAI adds no style: the browser look is kept. It also rewrites hash-only links such as href="#top", so use it with care.

        <head>

        MDN reference for the head element

        The part of the page the visitor never sees: the title, the character set, stylesheets, scripts and other settings for the browser.

        Markup only: this element is not rendered.

        HTML 
        <head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My page</title>
</head>

        CAI adds no style: the browser look is kept.

        <link>

        MDN reference for the link element

        Points the browser to a file the page needs, most often a stylesheet, but also icons and preloads. Load tokens first, then core, then platform.

        Markup only: this element is not rendered.

        HTML 
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/tokens@3.0.0/dist/cai-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@cai-ds/core@3.0.0/dist/cai.min.css">

        CAI adds no style: the browser look is kept.

        <meta>

        MDN reference for the meta element

        Settings and facts for browsers and search engines that have no tag of their own: character set, viewport, description, color scheme.

        Markup only: this element is not rendered.

        HTML 
        <meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="A vanilla design system in plain CSS.">

        CAI adds no style: the browser look is kept.

        <style>

        MDN reference for the style element

        CSS written straight into the page. Prefer a linked stylesheet, and keep this for a few lines of critical or generated CSS.

        Markup only: this element is not rendered.

        HTML 
        <style>
  .banner { padding: var(--cai-space-md); }
</style>

        CAI adds no style: the browser look is kept.

        <title>

        MDN reference for the title element

        The name of the page. Browsers show it in the tab, bookmarks and search results use it, and screen readers announce it first.

        Markup only: this element is not rendered.

        HTML 
        <title>HTML elements: CAI Design System</title>

        CAI adds no style: the browser look is kept.
