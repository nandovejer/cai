# Page structure

Build the big blocks of a page: landmarks, headings and the sections between them. They look like plain boxes; their value is what they tell assistive technology.

- `<address>`
- `<article>`
- `<aside>`
- `<footer>`
- `<h1>`
- `<h2>`
- `<h3>`
- `<h4>`
- `<h5>`
- `<h6>`
- `<header>`
- `<hgroup>`
- `<main>`
- `<nav>`
- `<search>`
- `<section>`
