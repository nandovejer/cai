        Show data in rows and columns. A bare table has no CAI style: add .cai-table, and wrap it in .cai-table-wrap so it can scroll.

        <caption>

        MDN reference for the caption element

        The title of a table, which screen readers read with it. It must be the first child of the table.

        Packages and their layer
        PackageLayer
        tokens1
        core2
        HTML 
        <div class="cai-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="cai-table">
    <caption>Packages and their layer</caption>
    <thead>
      <tr><th>Package</th><th>Layer</th></tr>
    </thead>
    <tbody>
      <tr><td>tokens</td><td>1</td></tr>
      <tr><td>core</td><td>2</td></tr>
    </tbody>
  </table>
</div>

        Styled through its class, from components/table.css.

        <col>

        MDN reference for the col element

        One column, or several with span, inside a colgroup. Use it to set the width, background or border of a whole column.

        PackageLayer
        tokens1
        core2
        HTML 
        <div class="cai-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="cai-table">
    <colgroup><col><col style="background: var(--cai-brand-subtle)"></colgroup>
    <thead>
      <tr><th>Package</th><th>Layer</th></tr>
    </thead>
    <tbody>
      <tr><td>tokens</td><td>1</td></tr>
      <tr><td>core</td><td>2</td></tr>
    </tbody>
  </table>
</div>

        CAI adds no style: the browser look is kept.

        <colgroup>

        <table>

        MDN reference for the table element

        Data in rows and columns that people compare, never page layout. Add .cai-table to the table and wrap it in .cai-table-wrap.

        PackageLayer
        tokens1
        core2
        HTML 
        <div class="cai-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="cai-table">
    <thead>
      <tr><th>Package</th><th>Layer</th></tr>
    </thead>
    <tbody>
      <tr><td>tokens</td><td>1</td></tr>
      <tr><td>core</td><td>2</td></tr>
    </tbody>
  </table>
</div>

        Styled through its class, from components/table.css. Under 480px of width the table stacks into cards: the header row is hidden from sight and stays available to screen readers.

        <th>

        MDN reference for the th element

        A cell that labels a row or a column. Set scope="col" or scope="row" so screen readers know which cells it labels.

        PackageLayer
        tokens1
        core2
        HTML 
        <div class="cai-table-wrap" tabindex="0" role="region" aria-label="Packages">
  <table class="cai-table">
    <thead>
      <tr><th scope="col">Package</th><th scope="col">Layer</th></tr>
    </thead>
    <tbody>
      <tr><th scope="row">tokens</th><td>1</td></tr>
      <tr><th scope="row">core</th><td>2</td></tr>
    </tbody>
  </table>
</div>

        Styled through its class, from components/table.css.
