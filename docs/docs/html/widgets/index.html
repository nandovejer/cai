Disclosure and dialogs, native and with no script needed.

<details>

MDN reference for the details element

Hides extra content behind a summary the user opens and closes, with no script needed. It starts closed unless you add open.

What is CAI?

A vanilla design system in plain CSS and ES modules.

HTML 
<details>
  <summary>What is CAI?</summary>
  <p>A vanilla design system in plain CSS and ES modules.</p>
</details>

Styled by elements/interactive.css, with no class.

<dialog>

MDN reference for the dialog element

A box above the page for a task or a message. Opened with showModal() it makes the rest of the page inert, shows a backdrop and closes with Escape. The button here opens it with no script.

A native dialog

Press Escape or the button to close it.
HTML 
<button class="cai-btn cai-btn--primary" type="button" command="show-modal" commandfor="d-dialog">Open dialog</button>
<dialog id="d-dialog" aria-labelledby="d-dialog-title">
  <h4 id="d-dialog-title">A native dialog</h4>
  <p>Press Escape or the button to close it.</p>
  <form method="dialog">
    <button class="cai-btn cai-btn--primary">Close</button>
  </form>
</dialog>

Styled by elements/interactive.css, with no class. A dialog with no class gets a surface and its centering back. .cai-modal is the component with a header, body and footer.

<geolocation>

Experimental MDN reference for the geolocation element

A button drawn by the browser that shares the visitor's location and handles the permission prompt itself. Experimental and of limited availability: check the compatibility table on MDN. The autolocate and watch attributes control when it reads the position.

Markup only: this element is not rendered.

HTML 
<geolocation>
  <button id="fallback">Use location</button>
</geolocation>

CAI adds no style: the browser look is kept.

<summary>

MDN reference for the summary element

The label of a details that always stays in view: clicking it opens and closes the rest. CAI gives it a hover and a focus ring.

</details>

Styled by elements/interactive.css, with no class.
