### How these pages work

- Every component and pattern page shows a live example and its known issues first, then two tabs: **Code** for developers and **Design** for designers.
- Pages open on Code. If you pick Design, the next page opens on Design too: this browser remembers your last choice, as it remembers the color mode. Nothing is sent anywhere.
- Without JavaScript, both tabs show one after the other.
