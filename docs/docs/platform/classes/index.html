Class reference

Every cai-platform class in one table.

Page structure

Class Element Description
.cai-platform-page
<body>
Root grid (header / 1fr / footer). Sets min-height: 100vh.
.cai-platform-page--gradient
<body>
Modifier. Adds a radial brand-subtle gradient at the top-left corner. Use on marketing or landing pages.
.cai-platform-skip-link
<a>
Visually hidden until focused. Jumps to #main-content. Required for keyboard accessibility.
.cai-platform-main
<main>
Main content area. Grid with gap: --cai-space-3xl between sections. Combine with .o-container for horizontal centering.
.cai-platform-content
<div> / <main>
Padded content wrapper with max-width cap. For app-shell layouts where the sidebar handles its own width.
.cai-platform-section
<section>
Grid container with vertical gap between child elements. Use as the direct child of .cai-platform-main.

Header and footer

Class Element Description
.cai-platform-page-header
<div> / <header>
Hero-style page header block with bottom margin. Contains a title and optional lead.
.cai-platform-page-header__title
<h1>
Heading: heading font, size 3xl, weight 300, tight letter-spacing.
.cai-platform-page-header__lead
<p>
Subtitle: secondary text color, max-width 600px.
.cai-platform-footer
<footer>
Flex row (space-between). Includes a top border and vertical padding. Collapses to column on mobile. Combine with .o-container.

Content patterns

Class Element Description
.cai-platform-actions
<div>
Flex row with wrapping and gap for CTA button groups. Collapses to column on mobile <480px.
.cai-platform-feature-grid
<div>
2-column grid for feature cards. Collapses to 1 column on mobile. Place .cai-card elements as direct children.
.cai-platform-command-block
<div>
Installation/CLI command display. Dark background, mono font. Flex row: command on left, copy button on right.
.cai-platform-command-block__cmd
<code>
The command text. Mono font, wraps on overflow.
.cai-platform-command-block__prefix
<span>
Shell prefix character ($, pnpm, etc.). Secondary color, non-selectable.
.cai-platform-image
<div>
16:9 frame around a native <picture>. The image fills it; with no image, an abstract placeholder shows, in a night version in dark mode.
.cai-platform-image--4x3, --3x2, --1x1, --21x9, --9x16
<div>
Modifiers. Other aspect ratios, each with its own placeholder.
