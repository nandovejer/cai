        Level 3 · @cai-ds/platform

        Page patterns built on core, from the page shell to the site search, and how to tell whether you need them.

        • Every class starts with .cai-platform- and uses semantic tokens only.
        • The CAI home page and these docs are built with them.

        Use platform when

        • You build a site or an app with a header, a main area and a footer on every page.
        • You want the same spacing and layout across many pages.
        • You want a skip link, a page header, feature grids and a site search without writing them yourself.

        Use core alone when

        • You only need components such as buttons, forms and cards.
        • You have your own layout system, or a framework that owns the page shell.
        • You build a single widget, not a whole page.

        Your own components on top

        Style what you add with semantic tokens too, so it follows the color mode and any custom theme.

        .my-panel {
  background: var(--cai-surface);
  border: 1px solid var(--cai-divider);
  color: var(--cai-text-primary);
}

.my-panel:hover {
  background: var(--cai-surface-muted);
  border-color: var(--cai-outline);
}

/* Not a primitive colour: it would stay the same in dark mode */
/* color: var(--cai-gray-100); */

        Patterns

        • Page shell

          Lays out a whole page: header, a main area that grows, and a footer that stays at the bottom.

        • Page header

          Gives a page its title and one sentence about what it is for.

        • Section

          Groups the blocks of one part of a page, with the same space between them everywhere.

        • Footer

          Ends every page with who made the site, its licence and a few secondary links.

        • Skip link

          Lets keyboard users jump past the header to the main content.

        • Action group

          Keeps two or three related buttons and links together in one row.

        • Command block

          Shows one shell command with a button that copies it.

        • Feature grid

          Lays out a short set of features or options of equal weight in two columns.

        • Image

          Shows a picture in a frame of fixed shape, with a placeholder when the picture is missing.

        • Search

          Finds a page, a section or an HTML element of a site by name, from a button in the header.
