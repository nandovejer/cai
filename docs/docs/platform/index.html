Level 3 · @cai-ds/platform

Page-level patterns built on core: the page shell, skip link, page header, sections, action groups, feature grids, command blocks, the footer and an image frame. The home page is built with them. Every class starts with .cai-platform- and uses semantic tokens only.

Use platform when

  • You build a site or an app with a header, a main area and a footer on every page.
  • You want the same spacing and layout across many pages.
  • You want a skip link, feature grids and action groups without writing the layout yourself.

Use core alone when

  • You only need components such as buttons, forms and cards.
  • You have your own layout system, or a framework that owns the page shell.
  • You build a single widget, not a whole page.

Your own components on top

Style what you add with semantic tokens too, never with the primitive scales, so it follows the color mode and any custom theme.

.my-panel {
  background: var(--cai-surface);
  border: 1px solid var(--cai-divider);
  color: var(--cai-text-primary);
}

.my-panel:hover {
  background: var(--cai-surface-muted);
  border-color: var(--cai-outline);
}

/* Avoid primitive scales in app-level components */
/* bad: color: var(--cai-gray-100); */

Patterns

  • Page shell

    Header, main and footer layout for every page.

  • Page header

    Title, lead and eyebrow at the top of a page.

  • Section

    A titled band of content with consistent spacing.

  • Footer

    Site footer with project links.

  • Skip link

    Lets keyboard users jump to the main content.

  • Action group

    A row of related buttons and links.

  • Command block

    A shell command with a copy button.

  • Feature grid

    A grid of short feature descriptions.

  • Image

    Responsive image frame with placeholders.
