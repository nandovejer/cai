        Skip link

        .cai-platform-skip-link

        Lets keyboard users jump past the header to the main content.

        Example

        This page has one: press Tab at the top of the page to see it.

        Known issues

        None known.

        Code Design

        Code

        Copy the markup

        HTML 
        <body>
  <a class="cai-platform-skip-link" href="#main-content">Skip to main content</a>
  <header>…</header>
  <main id="main-content" tabindex="-1">…</main>
</body>

        Variants and options

        There are no variants: one class on one link.

        ClassEffect
        .cai-platform-skip-link
        Off screen until it has focus, then fixed at the top start corner, in the brand fill, above everything

        How it works

        A normal link to the id of <main>, first in <body>, styled by @cai-ds/platform.

        • It slides in when it receives focus, over --cai-duration-fast; under reduced motion it appears at once.
        • The browser does the jump. tabindex="-1" on <main> lets it take the focus, so the next Tab starts inside it in every browser.

        Without JavaScript

        Nothing changes: the skip link is a link and CSS.

        Keyboard and ARIA

        Press Tab once from the top of the page and the link appears; Enter follows it to the main content.

        • It must be the first focusable element of the page.
        • No ARIA: its text is its name.

        Contrast and focus are in the Design tab.

        Design

        When to use

        Put a skip link on every page that has a header or navigation before the main content.

        When not to use

        Do not rely on it alone: the page still needs landmarks and a logical heading order.

        • Do not add a list of skip links to every section: one to the main content is enough.

        Do and don't

        Writing the content

        Say where it goes: "Skip to main content".

        • Use the same text on every page.

        Contrast and focus

        The link is white text on the brand fill, over the page.

        Measured from the token values of each mode, rounded down. Needs is the WCAG 2.2 AA minimum: 4.5:1 for text, 3:1 for focus rings, borders and icons.

        • Focus: the link slides into view when it takes focus, with the link ring, a 2 px --cai-focus-ring outline 2 px outside.

        Tokens it uses

        The 7 tokens that the .cai-platform-skip-link rules of platform's components/_components.css reads, by family. Each family links to its page, with the values in every mode. In Figma they are variables with the same names: see Tokens in Figma.

        Color
        --cai-brand-fill, --cai-text-on-fill
        Spacing and sizing
        --cai-space-sm, --cai-space-xs
        Motion
        --cai-duration-fast, --cai-easing-enter
        Layers and breakpoints
        --cai-z-toast
