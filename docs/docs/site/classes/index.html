        Page structure

        Class Element Description
        .cai-site-page
        <body>
        Three rows: header, main (takes the free space), footer. At least the height of the screen.
        .cai-site-page--gradient
        <body>
        Modifier. A soft brand tint in the top corner. For short pages such as a landing page.
        .cai-site-skip-link
        <a>
        Off screen until it has focus. Links to the id of <main>. First in <body> on every page.
        .cai-site-main
        <main>
        Main content area. Grid with gap: --cai-space-3xl between sections. Combine with .o-container for the content width and padding.
        .cai-site-content
        <div> / <main>
        Padded content wrapper with max-width cap. For app-shell layouts where the sidebar handles its own width.
        .cai-site-section
        <section>
        Grid container with vertical gap between child elements. Use as the direct child of .cai-site-main.

        Header and footer

        Class Element Description
        .cai-site-header
        <header>
        The site's banner: page surface and a rule underneath. --sticky keeps it at the top in a window at least 30 rem tall. Sets --cai-site-header-h, where the menu panel and the language list open.
        .cai-site-header__inner
        <div>
        The row: wraps, centred, with the gutters of .o-container.
        .cai-site-header__brand
        <a>
        The site's name, linked to the home page, not underlined; takes the free space of the row.
        .cai-site-header__nav
        <nav popover>
        The links: a row from 769 px, a panel under the header below it, opened by .cai-nav-toggle.
        .cai-site-header__actions
        <div>
        The controls at the end of the row: search, language switcher, a button.
        .cai-site-submenu
        <details>
        An item of the header’s links that holds more links: its <summary> is the button, with a chevron; its list opens under it, in the flow in the menu panel and in a box from 769 px. Give every submenu the same name.
        .cai-site-hero
        <section>
        The first block of a home or landing page, with space above it. Two equal columns when each gets 24rem and there is a picture; one below.
        .cai-site-hero__copy
        <div>
        The eyebrow, title, lead and actions, first in the source.
        .cai-site-hero__eyebrow
        <p>
        A short line above the title: mono, extra small, small capitals, secondary text color.
        .cai-site-hero__title
        <h1>
        Heading: heading font, size 4xl, weight 300, line height 1.1, balanced lines; 3xl below 1024 px, 2xl at 640 px and below.
        .cai-site-hero__lead
        <p>
        Secondary text color, size xl, max-width 70ch; lg below 1024 px, base at 640 px and below.
        .cai-site-hero__media
        <div>
        The second column, holding a .cai-site-image.
        .cai-site-page-header
        <div> / <header>
        Hero-style page header block with bottom margin. Contains a title and optional lead.
        .cai-site-page-header__title
        <h1>
        Heading: heading font, size 3xl, weight 300, tight letter-spacing.
        .cai-site-page-header__lead
        <p>
        Subtitle: secondary text color, max-width 600px.
        .cai-site-footer
        <footer>
        Flex row (space-between). Includes a top border and vertical padding. Stacks at 768 px and below. Combine with .o-container.

        Content patterns

        Class Element Description
        .cai-site-actions
        <div>
        Flex row with wrapping and gap for CTA button groups. One per line, full width, at 640 px and below.
        .cai-site-image
        <div>
        16:9 frame around a native <picture>. The image fills it; with no image, an abstract placeholder shows, in a night version in dark mode.
        .cai-site-image--4x3, --3x2, --1x1, --21x9, --9x16
        <div>
        Modifiers. Other aspect ratios, each with its own placeholder.

        Search

        Class Element Description
        .cai-site-search-trigger
        <button>
        The search button, shaped like a field: label, then the shortcut. Hidden in the markup; the script shows it.
        .cai-site-search-trigger--compact
        <button>
        Modifier. At 768 pixels and below, the magnifier only; the label stays its name.
        .cai-site-search-trigger__icon
        <svg>
        The magnifier, in the text color.
        .cai-site-search-trigger__label
        <span>
        The visible label, which is also the button’s name.
        .cai-site-search-trigger__key
        <kbd>
        The shortcut hint, "Ctrl K". Hidden on touch screens.
        .cai-site-search
        <dialog>
        With .cai-modal: the search dialog, a column whose results scroll; full screen at 768 pixels and below.
        .cai-site-search__body
        <search>
        The field, the status and the results.
        .cai-site-search__head
        <div>
        The title and the close button, in one row that wraps.
        .cai-site-search__title
        <h2>
        The dialog’s name; its label names the field.
        .cai-site-search__field
        <div>
        The field, with a decorative magnifier svg at its start.
        .cai-site-search__status
        <p>
        The count of results, role="status", small and muted.
        .cai-site-search__close
        <button>
        The close button, 44 pixels high, in a form method="dialog".
        .cai-site-search__results
        <div>
        The result groups: a heading and a list of links each.
        .cai-site-search__foot
        <p>
        The last line, with the link to the index page.

        Language switcher

        Class Element Description
        .cai-site-lang-switcher
        <div>
        The wrapper of the button and the list. Sets --cai-site-lang-switcher-top, how far down the list opens.
        .cai-site-lang-switcher__button
        <button>
        Opens the list with popovertarget. Shows the current language; its name starts with the label, hidden.
        .cai-site-lang-switcher__icon
        <svg>
        The globe, decorative, in the text color.
        .cai-site-lang-switcher__name
        <span>
        The current language’s name in the button. Clipped below 360 pixels, where the globe shows alone; it stays in the button’s name.
        .cai-site-lang-switcher__menu
        <nav>
        The popover with the list, fixed under the header at the end of the row.
        .cai-site-lang-switcher__title
        <p>
        The visible name of the list, which labels the nav.
        .cai-site-lang-switcher__list
        <ul>
        The languages, one per row, without bullets.
        .cai-site-lang-switcher__link
        <a>
        A language, named in itself, with lang and hreflang; bold and underlined with aria-current.

        Notice and cookie consent

        Class Element Description
        .cai-site-notice
        <section>
        A band above the site header with one short announcement and one link, its text in the header’s column. No script, no close button.
        .cai-site-notice--warning
        <section>
        The warning colours, for something that stops the visitor; the words say it too.
        .cai-site-consent
        <section hidden>
        The cookie banner, above the site header, in a <cai-site-consent>. Hidden in the markup: consent.js shows it when no answer is stored.
        .cai-site-consent__title
        <h2>
        The banner’s heading, in the sans; it names the region.
        .cai-site-consent__choices
        <details>
        The categories of optional cookies, as checkboxes in a form, under Accept and Reject.
