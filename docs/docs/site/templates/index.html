        Page templates

        Whole pages to paste in and adapt, a landing page shell and a content page, built from the site patterns.

        Each template is complete markup. Change the words and the links; keep the skip link, the single <h1> and the landmarks. The header is the site header.

        They use only the classes of core and site. The blocks that fill a landing page, from the hero to the registration form, are in Landing page templates.

        Landing page shell

        The page of a product or an event: skip link, site header, one section with the page header and its actions, and a footer. The landing page blocks go inside <main>.

        HTML 
        <body class="luz-site-page luz-site-page--gradient">
  <a class="luz-site-skip-link" href="#main-content">Skip to main content</a>

  <header class="luz-site-header">
    <div class="luz-site-header__inner">
      <button class="luz-nav-toggle" type="button" popovertarget="site-nav" aria-label="Menu">
        <svg viewBox="0 0 24 24" width="24" height="24" aria-hidden="true" focusable="false"><path fill="currentColor" d="M3 5h18v2H3zM3 11h18v2H3zM3 17h18v2H3z"/></svg>
      </button>
      <a class="luz-site-header__brand" href="/">Acme</a>
      <nav class="luz-site-header__nav" id="site-nav" aria-label="Main" popover>
        <ul>
          <li><a href="/" aria-current="page">Product</a></li>
          <li><a href="/pricing/">Pricing</a></li>
          <li><a href="/support/">Support</a></li>
        </ul>
      </nav>
    </div>
  </header>

  <main id="main-content" class="luz-site-main o-container">
    <section class="luz-site-section">
      <div class="luz-site-page-header">
        <h1 class="luz-site-page-header__title">Your product headline</h1>
        <p class="luz-site-page-header__lead">One sentence value proposition.</p>
      </div>

      <div class="luz-site-actions">
        <a class="luz-btn luz-btn--primary" href="#get-started">Get started</a>
        <a class="luz-btn luz-btn--outline" href="#learn-more">Browse the components</a>
      </div>
    </section>
  </main>

  <footer class="luz-site-footer o-container">
    <p>Footer text</p>
  </footer>
</body>

        Content page

        An article or a documentation page: a sticky site header, the page header, then one <section> for each heading.

        HTML 
        <body class="luz-site-page">
  <a class="luz-site-skip-link" href="#main-content">Skip to main content</a>

  <header class="luz-site-header luz-site-header--sticky">…</header>

  <main id="main-content" class="luz-site-main o-container">
    <div class="luz-site-page-header">
      <h1 class="luz-site-page-header__title">Title of the article</h1>
      <p class="luz-site-page-header__lead">One sentence about what it covers.</p>
    </div>

    <section class="luz-site-section" aria-labelledby="first-title">
      <h2 id="first-title">First section</h2>
      <p>The text.</p>
    </section>
  </main>

  <footer class="luz-site-footer o-container">
    <p>Footer text</p>
  </footer>
</body>
