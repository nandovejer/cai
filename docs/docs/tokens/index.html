        Tokens

        On this page

        Level 1 · @cai-ds/tokens

        CSS custom properties for every colour, space, size and type value. Use the semantic ones: they change with the color mode.

        Two layers

        • Primitives hold raw values: --cai-blue-60, --cai-space-md. They are the same in every mode.
        • Semantic tokens give a colour a job: --cai-text-primary, --cai-surface-page. Each mode points them at different primitives.
        • Space, size, radius, shadow and type scales are primitives that components use directly: they do not change with the mode.
        packages/tokens/tokens.json        the source of the primitives
packages/tokens/src/semantic.css   the semantic colours, per mode
dist/cai-tokens.css                both layers, and the ET Book font
dist/tokens.css                    both layers, no font

        Use semantic colours, never primitive ones

        A component that uses a primitive colour looks right in one mode and wrong in the others.

        /* Do: semantic tokens follow the mode */
.panel {
  color: var(--cai-text-primary);
  background: var(--cai-surface);
  border: 1px solid var(--cai-divider);
  padding: var(--cai-space-md);
}

/* Don't: a primitive colour stays the same in dark mode */
.panel {
  color: var(--cai-gray-100);
  background: var(--cai-blue-10);
}

        Text on a solid fill

        Behind --cai-text-on-fill, use a fill token, not the brand or status colour.

        • The fills: --cai-brand-fill, --cai-brand-fill-hover, --cai-brand-fill-active and --cai-color-danger-fill.
        • In light and high contrast they equal the brand and danger colours. In dark mode they are a step darker: the dark brand colour is light enough to read as text, and white on it falls below 4.5:1.

        Token families

        • Color

          Every colour a component may use, named by its job, with its value in light, dark and high contrast side by side.

        • Spacing and sizing

          The space scale for gaps and padding, and the heights of buttons and fields.

        • Typography

          The three font stacks, the type scale in rem, and the smallest size each kind of text may use.

        • Color modes and themes

          Switch between light, dark and high contrast with one attribute, or make a look of your own.

        • Radius

          The corner radius scale: square, 2px, 4px at most, and round.

        • Shadows

          The elevation scale: how far a surface seems to float above the page.

        • Motion

          The durations and easings of every transition, which drop to zero when the reader asks for reduced motion. Ships with @cai-ds/core.

        • Layers

          Which layer sits on top: the z-index of every overlay, in order. Ships with @cai-ds/core.

        • Layout and breakpoints

          How wide content gets, and where the layout changes. Ships with @cai-ds/core.

        • Color palette

          The primitive colour scales. For theme authors only: components never use them.

        • Tokens in Figma

          The tokens as one design-tokens file for Figma variables and other design tools, with the same names and the three modes.

        • Contrast check

          Check your own color overrides against the contrast CAI promises, with one command or in the page, before they reach a user.

        • Make your own theme

          CAI ships one look in three color modes. A theme of your own is a file of semantic tokens: start from the template, check it, load it.
