Motion

settings/_settings.css

Durations and easings, and how reduced motion stops them. Ships with @cai-ds/core.

Reduced motion is on, so the dots jump instead of travelling.

Durations

  • --cai-duration-instant 0.05s
  • --cai-duration-fast 0.1s
  • --cai-duration-base 0.2s
  • --cai-duration-slow 0.3s
  • --cai-duration-slower 0.5s
  • --cai-duration-lazy 0.8s

Easings

  • --cai-easing-standard cubic-bezier(0.3, 0, 0.1, 1)
  • --cai-easing-enter cubic-bezier(0.15, 0.6, 0.3, 1)
  • --cai-easing-exit cubic-bezier(0.5, 0, 0.85, 0.4)
  • --cai-easing-spring cubic-bezier(0.3, 1.35, 0.55, 1)
  • --cai-easing-linear linear

Ships with core, not with tokens.
