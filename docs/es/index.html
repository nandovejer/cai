        Light, Usable & Zero-dependency

        LUZ, un design system nativo y cuidado, pensado para la accesibilidad.

        Un design system para la web que parte del CSS y no necesita compilación. Tres modos de color, tu CSS siempre gana y JavaScript solo mejora la experiencia.

        Empezar Ver los componentes

        Por qué los equipos usan LUZ

        Para sitios y herramientas que tienen que funcionar para todo el mundo, en cualquier dispositivo y durante años, sin depender de un framework que haya que ir actualizando.

        • 01

          Funciona sin JavaScript

          Los componentes son elementos HTML nativos: <dialog>, <details>, controles de formulario, popovers. JavaScript solo mejora la experiencia, así que las páginas siguen funcionando aunque falle un script.

        • 02

          Pensado para la accesibilidad

          El uso con teclado, el foco visible, un contraste de texto de 4,5:1 y un modo de alto contraste forman parte de cada componente, y cada cambio pasa por pruebas automáticas. La declaración de accesibilidad, en inglés, recoge lo que aún no se ha probado, lectores de pantalla incluidos.

        • 03

          Nada que instalar para probarlo

          CSS plano y pequeños módulos ES, desde un CDN o desde npm. Sin preprocesador, sin compilador y sin dependencias: lo que lees en los archivos es lo que ejecuta el navegador.

        Adóptalo capa a capa

        Una sola dirección: cada paquete necesita los de debajo y ninguno de los de encima, y al instalarlo los trae. Elige el nivel que necesitas y quédate ahí.

        Nivel 1 Solo tokens

        Independiente

        Elígelo si ya tienes componentes o un framework y solo quieres valores coherentes y modos de color.

        Incluye

        • 53 colores primitivos en 7 familias
        • 55 tokens semánticos, cada uno definido para claro, oscuro y alto contraste
        • Espaciado (12), alturas de control (4), tamaños de texto (9), radios (6) y sombras (3)
        • ET Book para el texto corrido y los títulos, alojada en el propio paquete y con licencia MIT; fuentes del sistema para controles, etiquetas y código
        • Una comprobación de contraste para tus propios colores, como comando o en el navegador
        Instalar el nivel 1 Ver los tokens

        Nivel 2 Tokens + Core

        Necesita tokens

        Elígelo si construyes páginas o una aplicación y la maquetación de la página la pones tú.

        Añade al nivel 1

        • 32 componentes: botones, formularios, tablas, pestañas, diálogo modal, reproductor multimedia y más
        • 10 objetos de maquetación, unas pocas utilidades y los estilos de los elementos HTML sin necesidad de clases
        • JavaScript opcional para pestañas, diálogos, botones de copiar y reproductores; todas las páginas funcionan sin él
        • Estilos de impresión y soporte para escritura de derecha a izquierda, sin archivos adicionales
        • Todo en una sola capa de cascada, luz: tu propio CSS gana sin !important
        Instalar el nivel 2 Ver los componentes

        Nivel 3 Tokens + Core + Site

        Necesita core + tokens

        Elígelo si tu sitio necesita una búsqueda, un aviso de cookies o más de un idioma. Esta página usa este nivel.

        Añade al nivel 2

        • Consentimiento de cookies: una franja fija al pie de la ventana, que no tapa nada
        • Submenús para los enlaces de una cabecera, y un aviso encima de ella
        • Selector de idioma
        • Búsqueda en el sitio, con JavaScript opcional
        Instalar el nivel 3 Ver los patrones

        Siguiente: un paquete para tu tipo de sitio

        Sobre site se construyen paquetes para un tipo de sitio concreto. Instala el de arriba: trae todo lo que tiene debajo.

        • cms: un blog, un periódico o cualquier CMS, con cualquier tecnología. Cabecera de artículo, listados de entradas, índice del artículo y caja de autor.
        • landing: una landing page. La cabecera, la portada, las secciones y el pie de una landing page, además de ponentes y llamadas a la acción.
        • app: una aplicación web. La cabecera con búsqueda y cuenta, y un panel de control con paneles, sobre la barra lateral de core.
        tokens → core → site ─┬─ cms
                      ├─ landing
                      └─ app

        Cuándo encaja LUZ

        Encaja bien

        • Sitios de contenido, documentación y servicios públicos que deben cumplir WCAG 2.2 AA.
        • Páginas generadas en el servidor y sitios estáticos, con cualquier lenguaje de servidor.
        • Equipos que quieren entender su CSS y controlarlo.

        No encaja

        • Necesitas componentes de React o Vue ya hechos.
        • Necesitas una tabla de datos avanzada, gráficos o un selector de rango de fechas: LUZ no los incluye.
        • Necesitas una API estable hoy: LUZ está en beta y los nombres aún pueden cambiar.
