        Light, usable & zero-dependency

        LUZ, a design system for humans, ready for AI.

        Tokens, CSS and a little vanilla JavaScript, built on what the browser already does. Every component works before JavaScript loads, in light, dark and high contrast.

        We love TDD: every change starts with a failing test.

        Read the docs View on GitHub

        The light where you are

        With JavaScript on, the light of your hour is drawn here.

        Why LUZ

        Three words, one promise.

        A CSS-first, zero-build design system for the web. Your CSS always wins, JavaScript is only an enhancement, and every page works before it loads.

        Light

        Plain CSS and small ES modules from a CDN or npm. No preprocessor, no compiler: what you read in the files is what the browser runs.

        This page follows your clock. Tap a light to borrow another hour.

        Usable

        Native first: dialog, popover, details, range, progress. Keyboard support, visible focus and 4.5:1 text contrast are part of every component, not an option.

        That was the keyboard alone. Press Escape to close this note.

        The focus ring takes the color of the page’s actions, and it never hides.

        Zero-dependency

        0

        runtime dependencies. Nothing to install to try it, and no framework to keep up with for years.

        What’s inside

        Adopt it one layer at a time.

        One direction: each package needs the ones below it and nothing above it, and installing it brings them in. Pick the level you need and stop there.

        Level 1 Tokens only

        Standalone

        Choose this if you already have components or a framework and only want consistent values and color modes.

        You get

        • 53 color primitives and 55 semantic tokens, the semantic ones defined for light, dark and high contrast
        • Scales for spacing, control heights, type sizes, radii and shadows
        Install level 1 See the tokens

        Level 2 Tokens + Core

        Requires tokens

        Choose this if you are building pages or an app and bring your own page layout.

        Adds to level 1

        • 32 components, from buttons and forms to tabs and a media player, and 10 layout objects
        • Everything in one cascade layer, luz: your own CSS wins without !important
        Install level 2 See the components

        Level 3 Tokens + Core + Site

        Requires core + tokens

        Choose this if your site needs a search, a cookie banner or more than one language. This home page is built on it.

        Adds to level 2

        • Site search and a cookie consent band that covers nothing, with optional JavaScript
        • A language switch, submenus for the links of a header, and a banner above it
        Install level 3 See the patterns

        Level 4 · one package for your kind of site

        Each is built on site. Install the one for your site: it brings everything below it.

        • landing for a landing page
        • cms for a blog or a newspaper
        • app for a web application

        Works without JavaScript

        Starts from what the browser already does.

        Every component is a native element with a stylesheet on top. Switch JavaScript off and they still open, close, slide and choose.

        <details>

        What does “zero-build” mean?

        That there is no step between the files you read and the page the browser shows. Copy them, link them, done.

        <dialog>

        It opens with no script where the browser has command; elsewhere a small script opens it.

        A native dialog

        Focus moves into it, Escape closes it, and the browser keeps the page behind it out of reach. No library wrote any of that.

        Three color modes

        Light, dark, high contrast. And the hour.

        Every semantic color is defined for the three modes, and the data-theme attribute switches them, on the page or on one part of it. This page adds an axis of its own: the time where you are.

        Get started

        One link tag per layer.

        Pick a level, copy the snippet, ship. Pin an exact version while LUZ is in beta.

        From a CDN 
        <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/tokens@0.0.0/dist/luz-tokens.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@luz-ds/core@0.0.0/dist/luz.min.css">

<button class="luz-btn luz-btn--primary">Save changes</button>
<span class="luz-tag luz-tag--green luz-tag--dot">Published</span>

        This is what it renders

        Published
        From npm 
        npm install @luz-ds/tokens @luz-ds/core

import "@luz-ds/tokens/css";
import "@luz-ds/core/css";
import "@luz-ds/core";

        Then write HTML. <button class="luz-btn"> is a button. <dialog class="luz-modal"> is a modal. That is the whole idea.

        A good fit

        • Content sites, documentation and public services that must meet WCAG 2.2 AA.
        • Server-rendered pages and static sites, in any back-end language.
        • Teams that want to read and own their CSS.

        Not a good fit

        • You need ready-made React or Vue components.
        • You need a data grid, charts or a date-range picker: LUZ has none.
        • You need a stable API today: LUZ is in beta, and names can still change.
