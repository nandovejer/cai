Consistent Adaptive Identity

Plain CSS. Native APIs. No framework.

CAI is a vanilla design system: design tokens, components and app patterns written in plain CSS and ES modules on top of native browser APIs. Add a <link> tag and start. Nothing to compile, nothing to configure.

What CAI is

A design system you can read. Every file is CSS or JavaScript that the browser runs exactly as written.

  • 01

    Plain CSS

    Custom properties, media and container queries, keyframes. No preprocessor, no utility compiler, no CSS-in-JS.

  • 02

    ES modules

    One small module per behavior: tabs, modal, copy, player. Load them all with one script tag or import one at a time. Zero dependencies.

  • 03

    Native browser APIs

    <dialog>, <details>, native form controls, IntersectionObserver, Web Audio. If the platform already does it, CAI uses it.

  • 04

    Accessible by default

    Keyboard support, visible focus, ARIA state and a high-contrast mode are part of every component, not an add-on.

Adopt it one layer at a time

Three packages, one direction. Each layer needs the ones below it and nothing above it, so pick the level you need and stop there.

Level 1

Tokens only

Standalone

Your CSS, your components, CAI's values. One stylesheet of custom properties plus three MIT-licensed fonts.

  1. tokens
  2. core (not included)
  3. platform (not included)

You get

  • 48 color primitives in 7 families
  • 53 semantic tokens, each defined for light, dark and high contrast
  • Spacing (12), control heights (4), type sizes (9), radii (6) and shadows (3)
  • Gidole, ET Book and Monoid, self-hosted and MIT licensed

Stop here if

you already have components or a framework and only want consistent values and color modes.

See the tokens

Level 2

Tokens + Core

Requires tokens

Ready-made components and layout objects that consume the tokens, plus optional JavaScript for the interactive ones.

  1. tokens
  2. core
  3. platform (not included)

You get

  • 20 components: buttons, forms, tables, tabs, modal, media player and more
  • 7 layout objects and a small set of utilities
  • Motion, z-index and breakpoint settings
  • Optional cai.min.js: one ES module that wires tabs, modals, copy buttons, toggles and players

Stop here if

you are building pages or an app and bring your own page layout.

Installing with Yarn or pnpm?
pnpm add and yarn add take the same package lists. npm and pnpm install the required lower layers for you; Yarn only warns, so always list every package as shown.

On a CDN, pin the exact version and add an integrity hash in production.
