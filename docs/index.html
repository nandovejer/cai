        Light, Usable & Zero-dependency

        LUZ, a native, styled design system built for accessibility.

        A CSS-first, zero-build design system for the web. Three color modes, your CSS always wins, JavaScript only as an enhancement.

        Get started Browse the components

        Why teams use LUZ

        For sites and tools that should work for everyone, on any device, for years, without a framework to keep up with.

        • 01

          Works without JavaScript

          Components are native HTML elements: <dialog>, <details>, form controls, popovers. JavaScript only adds polish, so pages keep working when a script fails.

        • 02

          Built for accessibility

          Keyboard support, visible focus, 4.5:1 text contrast and a high-contrast mode are part of every component, and automated checks run on every change. The accessibility statement lists what has not been tested yet, screen readers included.

        • 03

          Nothing to install to try it

          Plain CSS and small ES modules from a CDN or npm. No preprocessor, no compiler, zero dependencies: what you read in the files is what the browser runs.

        Adopt it one layer at a time

        One direction: each package needs the ones below it and nothing above it, and installing it brings them in. Pick the level you need and stop there.

        Level 1 Tokens only

        Standalone

        Choose this if you already have components or a framework and only want consistent values and color modes.

        You get

        • 53 color primitives in 7 families
        • 55 semantic tokens, each defined for light, dark and high contrast
        • Spacing (12), control heights (4), type sizes (9), radii (6) and shadows (3)
        • ET Book for running text and headings, self-hosted and MIT licensed; the system fonts for controls, labels and code
        • A contrast check for your own colors, as a command or in the browser
        Install level 1 See the tokens

        Level 2 Tokens + Core

        Requires tokens

        Choose this if you are building pages or an app and bring your own page layout.

        Adds to level 1

        • 32 components: buttons, forms, tables, tabs, modal, media player and more
        • 10 layout objects, a small set of utilities and the styles of bare HTML elements
        • Optional JavaScript for tabs, modals, copy buttons and players; every page works without it
        • Print styles and right-to-left layouts, with no extra file
        • Everything in one cascade layer, luz: your own CSS wins without !important
        Install level 2 See the components

        Level 3 Tokens + Core + Site

        Requires core + tokens

        Choose this if your site needs a search, a cookie banner or more than one language. This landing is built at this level.

        Adds to level 2

        • Cookie consent: a band fixed at the bottom of the window, which covers nothing
        • Submenus for the links of a header, and a banner above it
        • Language switch
        • Site search, with optional JavaScript
        Install level 3 See the patterns

        Next: a package for your kind of site

        Packages for one kind of site build on site. Install the one at the top: it brings everything below it.

        • cms: a blog, a newspaper or any CMS, built with any stack. Article header, post lists, table of contents and author box.
        • landing: a landing page. The header, hero, sections and footer of a landing page, plus speakers and calls to action.
        • app: a web application. The header with search and account, and a dashboard of panels, on core's sidebar.

        When LUZ fits

        A good fit

        • Content sites, documentation and public services that must meet WCAG 2.2 AA.
        • Server-rendered pages and static sites, in any back-end language.
        • Teams that want to read and own their CSS.

        Not a good fit

        • You need ready-made React or Vue components.
        • You need a data grid, charts or a date-range picker: LUZ has none.
        • You need a stable API today: LUZ is in beta, and names can still change.
